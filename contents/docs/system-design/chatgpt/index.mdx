## 本题要练什么

会话存储、流式输出、模型路由、插件 / 工具、记忆、分层的安全防护、多租户配额。

## What this problem trains

Session storage, streaming, routing, plugins / tools, memory, layered safety, multi-tenant quotas.

## Whiteboard sketch

</Locale>

```
client (stream)
 → gateway / auth / quota
 → router (cheap/strong/tools)
 → session + memory
 → models
```

## 容易被追问

1. 跨会话的记忆怎么做，而且还能让用户关掉？（How do you build cross-session memory that users can turn off?）
2. 工具生态怎么隔离？（How do you isolate the tool ecosystem?）
3. 怎么防止单个用户把账单打爆？（How do you stop a single user from blowing up the bill?）
4. 流式输出时怎么做安全分类？（How do you run safety classification on streaming output?）
