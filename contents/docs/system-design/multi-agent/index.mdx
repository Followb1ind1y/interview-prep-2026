## 容易被追问

1. 什么时候应该用 multi-agent？（When should you use multi-agent?）
2. 用共享记忆还是消息传递？（Shared memory or message passing?）
3. 怎么防止两个 agent 互相覆盖对方的状态？（How do you stop two agents from overwriting each other's state?）
4. 成本模型怎么算？（How do you model the cost?）
