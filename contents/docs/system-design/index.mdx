## 开口框架

<Step>
  <StepItem title="澄清">
    用户量、读写比、延迟、一致性、是否要登录 / 搜索 / 实时。
  </StepItem>
  <StepItem title="估算">
    QPS、存储、带宽，先给数量级，再画图。
  </StepItem>
  <StepItem title="草图">
    Client → API Gateway → Services → Storage / Cache / Queue。
  </StepItem>
  <StepItem title="深挖">
    选 1–2 个难点：热点、一致性、推送、搜索、多机房。
  </StepItem>
</Step>
