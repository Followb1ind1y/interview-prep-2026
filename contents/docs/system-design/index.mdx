延迟 / 成本 / 可靠性 / 可观测性这些知识点在 [Production AI](/docs/production)。这里只练开口表达和权衡取舍。

每道题都按这 14 个维度走：

1. 需求（Requirements）
2. 约束（Constraints）
3. 架构（Architecture）
4. 数据流（Data Flow）
5. 模型（Model）
6. 检索（Retrieval）
7. 智能体（Agent）
8. 评测（Evaluation）
9. 扩展（Scaling）
10. 延迟（Latency）
11. 成本（Cost）
12. 可靠性（Reliability）
13. 安全（Security）
14. 可观测性（Observability）

The knowledge behind latency / cost / reliability / observability lives in [Production AI](/docs/production). This column is only for practicing how to talk through a design and its trade-offs.

Every problem goes through the same 14 dimensions:

1. Requirements
2. Constraints
3. Architecture
4. Data Flow
5. Model
6. Retrieval
7. Agent
8. Evaluation
9. Scaling
10. Latency
11. Cost
12. Reliability
13. Security
14. Observability

If a concept is shaky, go back to columns 01–07. The goal at this stage is **one problem a day**, not collecting new terms.
