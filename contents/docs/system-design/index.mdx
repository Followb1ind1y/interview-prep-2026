按题目练，不按维度收藏。机制知识在前面的栏目（[RAG](/docs/rag)、[Agent](/docs/agent)、[AI-Native](/docs/ai-native)、[Production AI](/docs/production)）；这一栏练的是**在 45 分钟里把一个系统讲清楚**。

## 45 分钟怎么讲

| 时间 | 做什么 | 每道题对应 |
| --- | --- | --- |
| 0–5 min | **澄清需求**：用户、规模、延迟、错误代价、成功指标；把假设写在白板上 | Level 0 |
| 5–10 min | **估算**：QPS、在途并发、token、存储、成本——并说出“所以难点在哪” | Level 0 |
| 10–20 min | **高层架构**：画数据流，走一遍一次请求 | Level 1 |
| 20–35 min | **挑两块深挖**：按“问题 → 方案 → 代价 → 怎么验证”讲 | Level 2–3 |
| 35–45 min | **评测、可靠性、安全、成本**：怎么证明好、挂了怎么办、花多少钱 | Level 4 |

每页末尾有一张 **14 维度速查表**，复习时用来检查有没有漏掉维度：需求、约束、架构、数据流、模型、检索、智能体、评测、扩展、延迟、成本、可靠性、安全、可观测性。不是每个维度都要讲——**估算结果决定深挖什么**。

## 建议顺序与优先级

| 优先级 | 题目 | 为什么 |
| --- | --- | --- |
| 🔴 必练 | [RAG Chatbot](/docs/system-design/rag-chatbot) | 所有题的基线 |
| 🔴 必练 | [Customer Support](/docs/system-design/customer-support) | RAG + 工具 + 写操作 + 转人工，最常考 |
| 🔴 必练 | [AI Agent](/docs/system-design/ai-agent) | 权限、注入、致命三要素 |
| 🔴 必练 | [Coding Agent](/docs/system-design/coding-agent) | 和你的日常经验直接相关 |
| 🔴 必练 | [AI Search](/docs/system-design/ai-search) | 扇出延迟与引用 |
| 🔴 必练 | [ChatGPT-like](/docs/system-design/chatgpt) | 规模估算到 GPU |
| 🔴 必练 | [Inference Platform](/docs/system-design/inference-platform) | 显存账与批处理（偏 infra 的岗位必考） |
| 🟡 选练 | [Knowledge Assistant](/docs/system-design/knowledge-assistant)、[Document Q&A](/docs/system-design/document-qa)、[Document Extraction](/docs/system-design/document-extraction)、[Meeting Summarization](/docs/system-design/meeting-summarization) | 各有一个独特考点：权限同步、长上下文取舍、人工复核、多阶段流水线 |

Practice problems, not dimension folders. Mechanics live in earlier sections ([RAG](/docs/rag), [Agent](/docs/agent), [AI-Native](/docs/ai-native), [Production AI](/docs/production)); here you practice presenting a system in 45 minutes.

## How to spend 45 minutes

| Time | What | Page level |
| --- | --- | --- |
| 0–5 min | **Clarify**: users, scale, latency, cost of errors, success metrics; write assumptions down | Level 0 |
| 5–10 min | **Estimate**: QPS, concurrency, tokens, storage, cost — and say where the difficulty lies | Level 0 |
| 10–20 min | **High-level design**: data flow, one request end to end | Level 1 |
| 20–35 min | **Two deep dives**: problem → solution → cost → validation | Levels 2–3 |
| 35–45 min | **Evaluation, reliability, security, cost** | Level 4 |

Each page ends with a 14-dimension cheat sheet for review. Not every dimension needs airtime — the estimates decide the deep dives.
