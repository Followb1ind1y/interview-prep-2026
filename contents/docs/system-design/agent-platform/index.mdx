<Note title="开口框架">

## 本题要练什么

平台题：租户、工具注册、权限、评测门禁、审计、MCP host。不是再设计一个聊天机器人。

## 白板草图

</Locale>

<Locale lang="en">

Design an enterprise agent platform.

<Note title="Opening framework">
Run every problem through the same 14 dimensions. Don't open by drawing microservices. If a concept is shaky, go back to columns 01–07 / 09.
</Note>

## What this problem trains

A platform problem: tenants, tool registration, permissions, eval gates, auditing, the MCP host. It's not another chatbot design.

## Whiteboard sketch

</Locale>

```
builders → register tools/agents (MCP)
        → policy / secrets / sandbox
        → runtime + traces + eval gates
        → business apps
```

## 容易被追问

1. 工具的发现和授权怎么做？（How do tool discovery and authorization work?）
2. 怎么防止一个团队的 agent 访问到另一个团队的数据？（How do you stop one team's agent from reaching another team's data?）
3. 平台层和应用层的 harness 怎么分层？（How do you split the harness between the platform layer and the application layer?）
4. 默认的评测门禁是什么？（What are the default eval gates?）
