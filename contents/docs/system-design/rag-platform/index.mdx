<Note title="Opening framework">
Run every problem through the same 14 dimensions. Don't open by drawing microservices. If a concept is shaky, go back to columns 01–07 / 09.

## What this problem trains

Platform-level ingestion, index lifecycle, hybrid retrieval, eval sets, quotas. Not another chatbot drawing.

## Whiteboard sketch

</Locale>

```
connectors → ingest workers → indexes (per tenant)
query API → hybrid + rerank → grounded generation
eval service → quality gates
```

## 容易被追问

1. 百万级文档的增量更新怎么做？（How do you do incremental updates across millions of documents?）
2. 租户隔离放在索引层还是过滤层？（Is tenant isolation done at the index layer or the filter layer?）
3. 怎么控制 embedding 的费用？（How do you control embedding costs?）
4. 平台的 SLO 和单个应用的 RAG 有什么不同？（How do platform SLOs differ from a single app's RAG?）
