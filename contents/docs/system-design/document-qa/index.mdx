## What this problem trains

Ingestion quality, tables, OCR, and page-level citations. Parent-child chunking is common here.

## Whiteboard sketch

</Locale>

```
PDF/HTML → parse (tables/OCR) → chunk + page metadata
         → retrieve → quote spans → answer
```

<Locale lang="zh">

## 容易被追问

1. 表格和正文怎么一起检索？（How do you retrieve tables and body text together?）
2. 怎么引用到具体的页码或段落？（How do you cite down to the page or paragraph?）
3. 长文档的 lost-in-the-middle 怎么处理？（How do you handle lost-in-the-middle on long documents?）
4. 用户上传的文档怎么做隔离和病毒扫描？（How do you isolate and virus-scan user-uploaded documents?）

## 14 个维度

```
1. 需求（Requirements）
2. 约束（Constraints）
3. 架构（Architecture）
4. 数据流（Data Flow）
5. 模型（Model）
6. 检索（Retrieval）
7. 智能体（Agent）
8. 评测（Evaluation）
9. 扩展（Scaling）
10. 延迟（Latency）
11. 成本（Cost）
12. 可靠性（Reliability）
13. 安全（Security）
14. 可观测性（Observability）
```
