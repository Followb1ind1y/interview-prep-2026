## 本题要练什么

必须异步。长 transcript 要 chunk + map-reduce 或长窗口 + 压缩。行动项要结构化输出。

## 白板草图

```
audio → ASR + diarization → transcript store
      → chunk summarize → reduce → actions/JSON
```

## 容易被追问

1. 2 小时会议如何避免丢 action item？
2. ASR 错误如何进 eval？
3. 为什么这题通常不是 agent？
4. 隐私和保留策略？
