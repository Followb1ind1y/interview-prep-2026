## 本题要练什么

必须异步处理。长转录稿要么切块做 map-reduce，要么用长窗口 + 压缩。行动项要用结构化输出。

## 白板草图

</Locale>

<Locale lang="en">

Design a meeting summarization system.

<Note title="Opening framework">
Run every problem through the same 14 dimensions. Don't open by drawing microservices. If a concept is shaky, go back to columns 01–07 / 09.
</Note>

## What this problem trains

It has to be asynchronous. Long transcripts need chunking with map-reduce, or a long window plus compression. Action items should come out as structured output.

## Whiteboard sketch

</Locale>

```
audio → ASR + diarization → transcript store
      → chunk summarize → reduce → actions/JSON
```
