## 本题要练什么

和玩具 chatbot 的区别在于权限、版本、审计和多数据源（wiki / Drive / 数据库）。接到 Unilever 的企业检索经验。

## 白板草图

</Locale>

<Locale lang="en">

Design an enterprise knowledge assistant.

<Note title="Opening framework">
Run every problem through the same 14 dimensions. Don't open by drawing microservices. If a concept is shaky, go back to columns 01–07 / 09.

## What this problem trains

What separates it from a toy chatbot: permissions, versioning, auditing, and multiple sources (wiki / Drive / databases). Tie it to the enterprise retrieval work at Unilever.

## Whiteboard sketch

</Locale>

```
User + identity
      ↓
ACL-aware retrieval (wiki / files / warehouse)
      ↓
Grounded answer + citations + audit log
```

<Locale lang="zh">

## 容易被追问

1. 怎么保证用户没有权限的文档不会被检索到？（How do you guarantee documents a user can't access never get retrieved?）
2. 文档更新后怎么让索引失效？（How do you invalidate the index when documents are updated?）
3. 多个数据源互相矛盾时信谁？（When sources conflict, which one do you trust?）
4. 怎么评估「找不到」比乱答更好？（How do you show that "I couldn't find it" beats a made-up answer?）
