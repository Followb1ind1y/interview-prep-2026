## 本题要练什么

和玩具 chatbot 的差别是权限、版本、审计、多源（wiki / Drive / DB）。接到 Unilever 企业检索经验。

## 白板草图

```
User + identity
      ↓
ACL-aware retrieval (wiki / files / warehouse)
      ↓
Grounded answer + citations + audit log
```

## 容易被追问

1. 没有权限的文档如何保证不会被检索到？
2. 文档更新如何失效索引？
3. 多源冲突时信谁？
4. 如何评「找不到」比乱答更好？
