## 本题要练什么

查询理解、混合检索、分面筛选、重排、生成式摘要片段。延迟预算比聊天机器人更紧。

## 白板草图

</Locale>

<Locale lang="en">

Design AI search.

<Note title="Opening framework">
Run every problem through the same 14 dimensions. Don't open by drawing microservices. If a concept is shaky, go back to columns 01–07 / 09.
</Note>

## What this problem trains

Query understanding, hybrid retrieval, facets, reranking, generated snippets. The latency budget is tighter than a chatbot's.

## Whiteboard sketch

</Locale>

```
query → rewrite / spell
      → sparse + dense + filters
      → rerank
      → results + optional AI overview
```

<Locale lang="zh">

## 容易被追问

1. AI 概览里的幻觉怎么让它有据可依？（How do you ground hallucinations in the AI overview?）
2. 过滤条件（价格、类目）和向量检索怎么组合？（How do you combine filters (price, category) with vector search?）
3. 返回空结果和返回不相关的结果，哪个更糟？（Which is worse: empty results or irrelevant results?）
4. 怎么对搜索质量做 A/B 测试？（How do you A/B test search quality?）
