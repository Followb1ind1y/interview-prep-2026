## 本题要练什么

query understanding、hybrid、facet、rerank、生成式 snippet。延迟预算比 chatbot 更紧。

## 白板草图

```
query → rewrite / spell
      → sparse + dense + filters
      → rerank
      → results + optional AI overview
```

## 容易被追问

1. Overview 幻觉如何接地？
2. 过滤器（价格、类目）和向量检索如何组合？
3. 空结果 vs 乱结果？
4. 如何 A/B 搜索质量？
