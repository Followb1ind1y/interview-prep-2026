## 本题要练什么

数据入库、切块、embedding、混合检索、重排、context 拼装、LLM 生成、引用来源、无答案处理。对照 [RAG Architecture](/docs/rag/architecture)。

## 白板草图

</Locale>

<Locale lang="en">

Design a RAG chatbot.

<Note title="Opening framework">
Run every problem through the same 14 dimensions. Don't open by drawing microservices. If a concept is shaky, go back to columns 01–07 / 09.
</Note>

## What this problem trains

Ingestion, chunking, embedding, hybrid search, reranking, context assembly, the LLM call, citations, and no-answer handling. Compare against [RAG Architecture](/docs/rag/architecture).

## Whiteboard sketch

</Locale>

```
User → API → Retriever → Rerank → LLM → Answer + citations
Docs → parse → chunk → embed → Vector DB + BM25
```

## 容易被追问

1. 怎么选 chunk size？（How do you choose chunk size?）
2. 为什么要用混合检索？（Why hybrid search?）
3. RAG 答错了，你查什么？（RAG answer is wrong. What do you investigate?）
4. 没有答案的查询怎么处理？（How do you handle no-answer queries?）
5. 怎么降低 RAG 的延迟？（How would you reduce RAG latency?）
