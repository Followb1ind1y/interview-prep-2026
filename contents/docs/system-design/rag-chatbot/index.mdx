## 本题要练什么

ingestion、chunk、embedding、hybrid、rerank、context、LLM、cite、no-answer。对照 [RAG Architecture](/docs/rag/architecture)。

## 白板草图

```
User → API → Retriever → Rerank → LLM → Answer + citations
Docs → parse → chunk → embed → Vector DB + BM25
```

## 容易被追问

1. How do you choose chunk size?
2. Why hybrid search?
3. RAG answer is wrong. What do you investigate?
4. How do you handle no-answer queries?
5. How would you reduce RAG latency?
