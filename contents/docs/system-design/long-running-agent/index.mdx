Conversation ≠ state. Persist the plan, progress, files, and errors. See [Agent State](/docs/ai-native/agent-state).

</Locale>

## 容易被追问

1. 怎么让长时间运行的 agent 可靠？（How do you make a long-running agent reliable?）
2. 进程被杀掉后怎么接着跑？（How does it resume after the process is killed?）
3. 上下文溢出时保留什么？（What do you keep when the context overflows?）
4. 用户中途改了目标怎么办？（What if the user changes the goal midway?）
