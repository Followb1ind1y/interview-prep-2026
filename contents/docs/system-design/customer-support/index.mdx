## 本题要练什么

workflow 和 agent 混合：查订单走工具，政策问题走 RAG，退款要人工确认。评测看问题解决率和错误退款。

## What this problem trains

A mix of workflow and agent: order lookups go through tools, policy questions through RAG, refunds through a human in the loop. Evaluate on resolution rate and wrongful refunds.

## Whiteboard sketch

</Locale>

```
Ticket
 ↓
intent / router
 ├── RAG (policy)
 ├── Tools (order, billing)
 └── Human escalation
```

## 容易被追问

1. 哪些动作必须人工确认？（Which actions must require human confirmation?）
2. 怎么避免 agent 过度承诺退款？（How do you keep the agent from over-promising refunds?）
3. 会话状态放在哪？（Where does conversation state live?）
4. 自助解决率和客户满意度怎么放在一起评？（How do you evaluate containment rate against CSAT?）
