## 本题要练什么

这是结构化输出 + workflow 的题，上 agent 往往太重。置信度低的结果交给人工。

## 白板草图

</Locale>

<Locale lang="en">

Design a document extraction pipeline.

<Note title="Opening framework">
Run every problem through the same 14 dimensions. Don't open by drawing microservices. If a concept is shaky, go back to columns 01–07 / 09.
</Note>

## What this problem trains

This is a structured output + workflow problem; an agent is usually overkill. Low-confidence results go to a human.

## Whiteboard sketch

</Locale>

```
docs → parse → LLM/JSON schema → validate
     → low confidence → human
     → warehouse
```
