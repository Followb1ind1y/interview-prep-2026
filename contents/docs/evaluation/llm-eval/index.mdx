## 需要掌握

- exact match
- BLEU / ROUGE（知道即可）
- semantic similarity
- LLM-as-a-judge
- pairwise evaluation
- rubric-based evaluation

## 机制

```
reference-based     exact / overlap / embedding similarity
reference-free      judge model + rubric / pairwise
```

## 三级回答

### Level 1 — Definition

对自由文本输出打分。有的对照参考答案，有的用更强模型当法官。

### Level 2 — Mechanism

LLM-as-judge 用 rubric 降主观噪声。Pairwise 比绝对分更稳。BLEU / ROUGE 对对话类任务很弱，知道局限即可。

### Level 3 — Engineering

Judge 会偏爱某风格、会被位置影响。要抽检人工对齐，固定 judge 模型版本。
