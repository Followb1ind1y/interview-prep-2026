## 机制

```
Offline Eval
      ↓
Staging
      ↓
Production
      ↓
Trace
      ↓
Failure
      ↓
Dataset
      ↓
New Eval
      ↓
Regression Test
```

## 三级回答

### Level 1 — Definition

把线上失败变成离线回归，形成闭环。

### Level 2 — Mechanism

Trace 记录 prompt 版本、检索、工具、输出。失败样本人工或 judge 标注后进入 golden set。

### Level 3 — Engineering

没有这条环，eval 会和真实用户脱节。Staging 要用生产流量的影子或回放。
