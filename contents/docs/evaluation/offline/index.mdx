## 需要掌握

- golden dataset

## 机制

```
golden set → run system → scores → pass/fail gate
online A/B → 真实用户 → 延迟确认
```

## 三级回答

### Level 1 — Definition

离线用冻结的标注集反复跑；线上用分流看真实指标。

### Level 2 — Mechanism

Golden set 要覆盖失败模式，不只 happy path。Regression 绑 CI。A/B 验证离线分高的改动真的对用户好。

### Level 3 — Engineering

集太小会过拟合评测。生产失败要回流进 golden set，见 Production Eval。
