## 机制

```
retriever metrics     金标文档在不在 Top-K
generator metrics     有没有编造、有没有回答问题
```

## 三级回答

### Level 1 — Definition

RAG 要同时评「找对了没有」和「写对了没有」。

### Level 2 — Mechanism

Recall 低先修检索。Recall 高但 faithfulness 低，是生成不守证据或 context 拼坏了。

### Level 3 — Engineering

90% recall、70% answer accuracy：按 [Failure Diagnosis](/docs/rag/debugging) 往下拆，不要只调生成温度。
