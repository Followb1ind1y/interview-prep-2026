## 三级回答

### Level 1 — Definition

用固定输入和可比较的分数，判断系统是否变好。

### Level 2 — Mechanism

没有 expected，就只能看偏好或人工。Metric 必须和产品目标一致：检索看 recall，客服看解决率。

### Level 3 — Engineering

没有这一环，所有 RAG / Agent 改动都是感觉。Eval-driven：先有集，再改系统。
