## 三级回答

### Level 1 — 定义

用固定的输入和可比较的分数，判断系统是不是变好了。

### Level 2 — 机制

没有参考答案，就只能看偏好或靠人工判断。指标必须和产品目标一致：检索看召回率，客服看问题解决率。

### Level 3 — 工程

没有这一环，所有 RAG / Agent 的改动都只是凭感觉。评测驱动：先有评测集，再改系统。

## Three-level answers

### Level 1 — Definition

Using fixed inputs and comparable scores to tell whether the system actually got better.

### Level 2 — Mechanism

Without an expected output, all you have is preference or human judgment. The metric has to match the product goal: recall for retrieval, resolution rate for customer support.

### Level 3 — Engineering

Without this loop, every RAG or agent change is just a feeling. Eval-driven means: build the eval set first, then change the system.
