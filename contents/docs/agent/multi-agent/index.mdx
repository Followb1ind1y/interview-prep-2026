## 三级回答

### Level 1 — 定义

多个拥有不同工具 / 指令的 agent 协作完成一个任务。

### Level 2 — 机制

Router 负责分发；Supervisor 负责编排和汇总；specialist 在单一领域深挖。可以并行，也可以分层。

### Level 3 — 工程

拆分会增加交接时的信息丢失和延迟。只有工具集、指令或权限真的不同时才拆。单个 agent + 好用的工具，往往更稳定。

## 我的答案

</Locale>

<Locale lang="en">

Common reasons it ends up worse: latency, cost, context fragmentation, coordination failures, error propagation.

## Three-level answers

### Level 1 — Definition

Several agents, each with its own tools and instructions, working together on one task.

### Level 2 — Mechanism

A router dispatches; a supervisor orchestrates and aggregates; specialists go deep in a single domain. They can run in parallel or in a hierarchy.

### Level 3 — Engineering

Splitting adds handoff loss and latency. Only split when the tool sets, instructions, or permissions genuinely differ. A single agent with good tools is often more stable.
