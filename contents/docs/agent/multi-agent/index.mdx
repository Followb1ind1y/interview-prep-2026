## 需要掌握

- supervisor
- router
- specialist agents
- parallel / sequential / hierarchical agents

## 机制

```
Router / Supervisor
        ↓
   specialist A / B / C
```

更差的常见原因：latency、cost、context fragmentation、coordination failure、error propagation。

## 三级回答

### Level 1 — Definition

多个有不同工具 / 指令的 agent 协作完成任务。

### Level 2 — Mechanism

Router 做分发；Supervisor 做编排和汇总；specialist 深挖单域。可并行或层级。

### Level 3 — Engineering

拆分增加交接丢失和延迟。只有工具集、指令或权限真正不同时才拆。单 agent + 好 tools 往往更稳。
