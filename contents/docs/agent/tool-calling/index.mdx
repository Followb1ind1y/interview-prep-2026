## 需要掌握

- function calling
- tool schema
- tool selection
- tool arguments
- validation
- execution
- tool result
- retry / timeout
- idempotency

## 机制

```
LLM → choose tool + args → validate
    → execute → tool result → LLM
```

## 三级回答

### Level 1 — Definition

模型输出结构化的工具名和参数，由运行时执行，再把结果喂回模型。

### Level 2 — Mechanism

Schema 限制可调用面。校验挡住幻觉参数。超时和重试要考虑幂等，避免重复下单 / 重复写。

### Level 3 — Engineering

工具失败不是「再问一次模型」就完。要分类：参数错、下游 5xx、权限、超时。过多 tool 会降低选择准确率，转到 Context Construction。
