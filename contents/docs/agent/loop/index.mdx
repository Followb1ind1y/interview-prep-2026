## 三级回答

### Level 1 — 定义

Agent 在环境里循环：观察状态、做决定、执行动作、再看结果。

### Level 2 — 机制

没有 loop，就只是一次 LLM 调用。工具结果、检索内容、代码输出都必须回到模型，模型才能纠错和继续。

### Level 3 — 工程

Loop 会带来死循环、费用和延迟问题，所以必须有最大迭代次数、超时和预算。典型题：「你的 agent 偶尔会循环 20 步，每次请求花 $0.50，怎么排查和修复？」

## Three-level answers

### Level 1 — Definition

An agent runs in a loop inside an environment: observe the state, decide, act, then look at the result.

### Level 2 — Mechanism

Without the loop, it's just a single LLM call. Tool results, retrieved content, and code output all have to flow back to the model so it can correct itself and keep going.

### Level 3 — Engineering

The loop brings infinite loops, cost, and latency with it, so you need max iterations, timeouts, and budgets. Classic question: "Your agent occasionally loops for 20 steps and costs $0.50 per request. How do you debug and fix it?"

## Interview questions
