
## 三级回答

### Level 1 — Definition

Agent 是在环境中循环：看状态、决定、行动、再看结果。

### Level 2 — Mechanism

没有 loop 就只是一次 LLM 调用。工具结果、检索、代码输出都必须回到模型，才能纠正和继续。

### Level 3 — Engineering

Loop 带来无限循环、费用和延迟。必须有 max iterations、timeout、budget。Your agent occasionally loops for 20 steps and costs $0.50 per request. How do you debug and fix it?
