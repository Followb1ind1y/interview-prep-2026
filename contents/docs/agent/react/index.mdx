## 机制

```
Thought
 ↓
Action
 ↓
Observation
 ↓
Thought
```

## 三级回答

### Level 1 — Definition

ReAct 把推理痕迹和行动交错，用观察更新下一步。

### Level 2 — Mechanism

Thought 帮助分解；Action 调工具；Observation 是环境反馈。这是 loop 的一种提示格式。

### Level 3 — Engineering

纯 ReAct 难控步数和费用。生产里常用结构化 tool calling + 显式状态机 / graph，而不是自由 Thought 文本。
