## 三级回答

### Level 1 — 定义

把目标拆成可以执行的步骤，并根据反馈修改计划。

### Level 2 — 机制

Plan-and-execute 先定好计划再执行。Dynamic planning 每一步都重新思考。Reflection / verification 负责检查结果对不对。

### Level 3 — 工程

过度规划会浪费 token。缺少验证环节的 coding agent 会很自信地交出错误代码。接到 Agentic Coding 里的反馈闭环。

## Three-level answers

### Level 1 — Definition

Breaking a goal into executable steps and revising the plan based on feedback.

### Level 2 — Mechanism

Plan-and-execute commits to a plan up front and then runs it. Dynamic planning rethinks at every step. Reflection and verification check whether the result is actually right.

### Level 3 — Engineering

Over-planning burns tokens. A coding agent without verification will confidently ship broken code. This connects to the feedback loop in Agentic Coding.
