## 机制

```
Goal → Plan → Execute step
            → Observe
            → Replan / Reflect / Verify
```

## 三级回答

### Level 1 — Definition

把目标拆成可执行步骤，并在反馈后修改计划。

### Level 2 — Mechanism

Plan-and-execute 先计划再跑。Dynamic planning 每步重想。Reflection / verification 检查对错。

### Level 3 — Engineering

过度规划浪费 token。缺 verification 的 coding agent 会自信地交错误代码。接到 Agentic Coding 的 feedback loop。
