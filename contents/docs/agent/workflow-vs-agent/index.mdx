<Locale lang="zh">

## 三级回答

### Level 1 — 定义

Workflow 的路径是预先定义好的。Agent 由模型在运行时选择下一步。

### Level 2 — 机制

确定性的步骤（抽取字段 → 校验 → 写库）用 workflow。只有分支取决于未知环境和工具结果时，才需要 agent。

### Level 3 — 工程

Agent 的代价是延迟、成本和结果不可复现。能用 workflow 解决的，就不要再包一层「智能」。

## Three-level answers

### Level 1 — Definition

A workflow follows a predefined path. An agent lets the model pick the next step at runtime.

### Level 2 — Mechanism

Deterministic steps (extract fields → validate → write to the DB) belong in a workflow. You only need an agent when branching depends on an unknown environment and tool results.

### Level 3 — Engineering

An agent costs you latency, money, and reproducibility. If a workflow solves it, don't wrap it in a layer of "intelligence."
