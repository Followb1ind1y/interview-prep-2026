固定流程通常更便宜、更可预测。2026 面试资料特别强调这一点。

## 需要掌握

能画两种控制流，能举一个自己做过的「不该上 agent」的例子。

## 机制

```
Workflow
A → B → C → D

Agent
A → LLM decides → B
                  ↓
                  C
                  ↓
                  A again
```

## 三级回答

### Level 1 — Definition

Workflow 预定义路径。Agent 由模型在运行时选择下一步。

### Level 2 — Mechanism

确定性步骤（抽字段 → 校验 → 写库）用 workflow。分支依赖未知环境和工具结果时，才需要 agent。

### Level 3 — Engineering

Agent 的代价是延迟、成本、不可复现。能 workflow 解决的不要包一层「智能」。
