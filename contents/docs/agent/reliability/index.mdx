## 需要掌握

- max iterations
- timeout
- retry / exponential backoff
- circuit breaker
- tool failure
- hallucinated tool arguments
- infinite loops / stuck agents
- fallback
- human-in-the-loop
- budget limits

## 机制

```
budget / max steps / timeout
        ↓
retry with backoff
        ↓
circuit breaker / fallback model
        ↓
human escalation
```

## 三级回答

### Level 1 — Definition

保证 agent 在失败、幻觉、卡住时仍然停得下来、降级得了、转得走人工。

### Level 2 — Mechanism

步数和预算是硬限制。工具层 retry 与模型层 fallback 分开。熔断避免下游被打爆。

### Level 3 — Engineering

Your agent loops 20 steps and costs $0.50：查是否缺终止条件、工具是否总失败、prompt 是否鼓励「再试一次」、有没有重复同参调用。
