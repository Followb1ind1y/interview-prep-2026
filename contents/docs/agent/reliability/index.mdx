## 三级回答

### Level 1 — 定义

保证 agent 在失败、幻觉、卡住的时候，仍然停得下来、能降级、能转给人工。

### Level 2 — 机制

步数和预算是硬性限制。工具层的重试和模型层的降级要分开处理。熔断避免把下游服务打垮。

### Level 3 — 工程

「你的 agent 循环了 20 步、花了 $0.50」：查是不是缺终止条件、工具是不是一直在失败、prompt 是不是在鼓励「再试一次」、有没有用相同参数重复调用。

## 面试问题

4. 哪些失败必须人工介入，哪些可以自动降级？（Which failures require a human in the loop, and which can fall back automatically?）

## Three-level answers

### Level 1 — Definition

Making sure that when an agent fails, hallucinates, or gets stuck, it can still stop, degrade gracefully, and hand off to a human.

### Level 2 — Mechanism

Step counts and budgets are hard limits. Tool-level retries and model-level fallbacks are handled separately. Circuit breakers keep you from hammering downstream services.

### Level 3 — Engineering

"Your agent loops for 20 steps and costs $0.50": check for a missing stop condition, a tool that keeps failing, a prompt that encourages "try again," and repeated calls with identical arguments.

## Interview questions

1. How do you prevent infinite loops?
2. What if a tool fails?
3. Should budget limits be measured in tokens, dollars, or steps?
4. Which failures require a human in the loop, and which can fall back automatically?
