## 机制

```
exact kNN  →  O(N·d)  精确但不可扩
ANN        →  近似最近邻，换 recall 换延迟
```

## 三级回答

### Level 1 — Definition

在高维向量里找近邻。生产用近似算法，不是全量扫描。

### Level 2 — Mechanism

HNSW 是图索引；IVF 先聚类再扫描部分桶；PQ 压缩向量降内存。Metadata filter 与向量检索的顺序影响召回。

### Level 3 — Engineering

N 到百万以上 brute-force 延迟和 CPU/GPU 都不划算。调 HNSW ef / IVF nprobe 是 recall–latency 曲线，不是开关。
