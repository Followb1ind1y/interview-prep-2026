## 需要掌握

- BM25
- inverted index
- keyword search

## 机制

```
term → posting list → BM25 score
语义近但用词不同 → dense 赢
用词精确但语义模型稀释 → BM25 赢
```

## 三级回答

### Level 1 — Definition

基于词项统计的检索。BM25 是最常见的稀疏打分。

### Level 2 — Mechanism

倒排索引列出含某词的文档。BM25 惩罚过长文档、过常见词。

### Level 3 — Engineering

和 dense 互补：一个抓同义，一个抓精确匹配。这是 hybrid 的理由，不是「BM25 过时了」。
