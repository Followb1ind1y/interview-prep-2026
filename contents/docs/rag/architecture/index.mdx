## 三级回答

### Level 1 — Definition

RAG 用检索到的证据当上下文，而不是只靠参数记忆。

### Level 2 — Mechanism

离线建索引，在线问句 → 检索 →（可选）rerank → 拼 context → 生成。

### Level 3 — Engineering

生产 RAG 还有 ingestion 质量、权限过滤、版本、评测和延迟预算。错答先走 [Failure Diagnosis](/docs/rag/debugging)，不要先换模型。
