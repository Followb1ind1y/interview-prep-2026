## 三级回答

### Level 1 — 定义

把各种格式的文档变成可以切块、可以追溯来源的文本 + 元数据。

### Level 2 — 机制

解析器按文件类型分别处理；表格和扫描件要做 OCR，并保留结构。元数据（来源、时间、权限、版本）留给后续过滤和引用。

### Level 3 — 工程

文档版本更新时必须能让旧 chunk 失效。权限字段要进元数据过滤，不能只靠 prompt 里写一句「不要看机密内容」。

## Three-level answers

### Level 1 — Definition

Turning documents in every format into text plus metadata that can be chunked and traced back to its source.

### Level 2 — Mechanism

Parsers handle each file type separately; tables and scans need OCR with their structure preserved. Metadata (source, timestamp, permissions, version) is kept for filtering and citations later.

### Level 3 — Engineering

When a document gets a new version, the old chunks have to be invalidated. Permission fields belong in the metadata filter — you can't rely on a prompt that says "don't look at confidential content."
