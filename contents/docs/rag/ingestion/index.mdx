## 机制

```
Raw files → parse → clean → attach metadata → version → chunk
```

## 三级回答

### Level 1 — Definition

把各格式文档变成可切块、可追溯的文本 + 元数据。

### Level 2 — Mechanism

解析器按类型处理；表和扫描件要 OCR / 结构保留。Metadata（source、时间、权限、版本）留给过滤和引用。

### Level 3 — Engineering

版本更新必须能失效旧 chunk。权限字段要进 metadata filter，不能只靠 prompt「不要看机密」。
