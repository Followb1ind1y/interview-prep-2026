## 机制

```
text → embedding model → vector
query vec · doc vec  →  ranking score
```

## 三级回答

### Level 1 — Definition

把文本变成稠密向量，语义近的点在空间里近。

### Level 2 — Mechanism

余弦 = 方向；点积受模长影响，常先归一化。Query 和 document 有时用非对称模型。

### Level 3 — Engineering

换 embedding 要重建索引。维度越大不一定越好，但一定更贵。领域词表差要用领域模型或 hybrid。
