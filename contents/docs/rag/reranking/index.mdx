## 需要掌握

Retrieval 便宜、粗；rerank 贵、准。

## 机制

```
Top 50 retrieved
        ↓
Cross Encoder / Reranker
        ↓
Top 5
```

## 三级回答

### Level 1 — Definition

用更强（通常是 cross-encoder）模型重排少量候选。

### Level 2 — Mechanism

Bi-encoder 把 query / doc 分开编码才能预计算。Cross-encoder 联合编码，质量高但无法对全库跑。

### Level 3 — Engineering

Rerank 深度和候选集大小直接打延迟。没有 rerank 时，把更好的 hybrid 和 metadata 做好。有 rerank 就要进 trace。
