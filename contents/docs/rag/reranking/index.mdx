Top 50 retrieved

<Locale lang="zh">

## 三级回答

### Level 1 — 定义

用更强的模型（通常是 cross-encoder）对少量候选重新排序。

### Level 2 — 机制

Bi-encoder 把 query 和文档分开编码，所以文档向量可以预先算好。Cross-encoder 把两者放在一起编码，质量高，但没法对全库跑。

### Level 3 — 工程

重排的深度和候选集大小直接决定延迟。没有 rerank 时，就把 hybrid 和元数据过滤做好。上了 rerank，就要把它纳入链路追踪（trace）。

## Three-level answers

### Level 1 — Definition

Re-sorting a small set of candidates with a stronger model, usually a cross-encoder.

### Level 2 — Mechanism

A bi-encoder encodes the query and documents separately, which is what lets document vectors be precomputed. A cross-encoder encodes them together — higher quality, but impossible to run across the whole corpus.

### Level 3 — Engineering

Rerank depth and candidate-set size directly drive latency. Without a reranker, invest in better hybrid search and metadata. With one, make sure it shows up in your traces.
