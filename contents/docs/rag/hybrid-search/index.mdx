## 三级回答

### Level 1 — Definition

同时用词面和语义两路检索，再融合排序。

### Level 2 — Mechanism

加权融合要校准分数尺度。RRF 用名次融合，少调参、更稳。

### Level 3 — Engineering

两路都要能被 metadata filter。融合后再 rerank。延迟是两路并行 + 融合，不是简单「加一次检索」。
