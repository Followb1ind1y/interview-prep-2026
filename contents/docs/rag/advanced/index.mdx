## 机制

```
User query → rewrite / expand / HyDE
          → retrieve (maybe multi-hop / graph)
          → construct context
```

## 三级回答

### Level 1 — Definition

在基础 RAG 上增加 query 侧或图结构侧的推理，处理改写、多跳、关系。

### Level 2 — Mechanism

HyDE 先生成假设答案再嵌入检索。Multi-hop 把中间答案变成下一跳 query。GraphRAG 用实体关系补向量检索的局部性。Agentic RAG 让模型决定是否再搜。

### Level 3 — Engineering

每多一跳就多延迟和费用。先证明基础召回不够，再加组件。用 eval 证明 rewrite 有用。
