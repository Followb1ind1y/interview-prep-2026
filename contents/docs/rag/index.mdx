不要只停在 Embedding / Retrieval / Reranking / Hybrid Search。最终要能在白板上 5 分钟设计 Enterprise RAG，并且回答：*RAG answer is wrong. What do you investigate?*

```
Documents → Parsing → Chunking → Embedding → Vector DB
         → Query → Retrieval → Reranking → Context → LLM → Answer
```

评测（Recall@K、Faithfulness）在 [Evaluation / RAG Eval](/docs/evaluation/rag-eval)，本专栏只保留系统和诊断。
