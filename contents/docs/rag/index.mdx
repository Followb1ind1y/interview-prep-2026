## 建议学习顺序

1. **先看全貌：** Architecture → Ingestion → Chunking。先把原文、解析、证据单元与版本弄清。
2. **再学检索：** Embedding → Vector Search → Sparse Retrieval → Hybrid Search。先分别理解两路，再手算 RRF。
3. **最后优化与排错：** Reranking → Failure Diagnosis → Advanced RAG。高级策略要由具体失败案例驱动。

每页有 Level 0–3、贯穿的 `P-17 v3` 退款政策案例与逐级自测。学习后用 `/drill rag/<页面 slug>` 口头作答；课件生成不代表已经掌握。

## Suggested order

1. **Build the map:** Architecture → Ingestion → Chunking. Establish source truth, parsing, evidence units, and versions.
2. **Learn retrieval:** Embedding → Vector Search → Sparse Retrieval → Hybrid Search. Understand each branch before calculating RRF.
3. **Optimize and debug:** Reranking → Failure Diagnosis → Advanced RAG. Advanced methods should address observed failures.

Each page has Levels 0–3, one `P-17 v3` refund-policy example, and self-checks. Use `/drill rag/<page slug>` after reading; generated notes do not count as mastery.
