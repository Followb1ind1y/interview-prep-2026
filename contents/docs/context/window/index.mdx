## 需要掌握

- context limit
- input tokens / output tokens
- attention cost
- long context degradation
- lost-in-the-middle

## 机制

```
input tokens + reserved output ≤ context limit
attention ~ O(n²)  （或稀疏变体，仍然随 n 变贵）
```

## 三级回答

### Level 1 — Definition

模型单次能处理的最大 token 数，输入和输出通常共享或分别计。

### Level 2 — Mechanism

n 变大，attention 和 KV 都变贵。中间位置的证据更容易被忽略（lost-in-the-middle）。

### Level 3 — Engineering

有 1M window 也不该把整个语料塞进去。检索、压缩、缓存仍然必要。
