## 机制

```
100k tokens
     ↓
Conversation summary
     ↓
Relevant facts
     ↓
20k tokens
```

## 三级回答

### Level 1 — Definition

在丢失最少关键信息的前提下减少 token。

### Level 2 — Mechanism

可删旧轮次、摘要历史、截断工具输出、只留结构化事实。Rolling summary 随对话更新。

### Level 3 — Engineering

摘要本身会丢决策和错误。对 coding / long-running agent，用 [Compaction](/docs/ai-native/compaction) 的保留清单，而不是「把聊天总结一下」。
