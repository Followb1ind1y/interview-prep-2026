## 需要掌握

只放当前任务需要的记忆、文档、工具和状态。

## 机制

```
User
 ↓
Relevant memory
 ↓
Relevant documents
 ↓
Relevant tools
 ↓
Current task state
 ↓
LLM
```

## 三级回答

### Level 1 — Definition

按当前步的目标组装最小充分上下文。

### Level 2 — Mechanism

用检索、规则、权限、工具相关性做选择。顺序也有意义：指令、证据、问题。

### Level 3 — Engineering

工具定义过多会干扰选 tool。历史过长会淹没当前问题。这是 Agent 可靠性和成本的同一杠杆。
