## 三级回答

### Level 1 — Definition

模型一次前向能看到的全部 token，不只有用户那句话。

### Level 2 — Mechanism

每一类信息都占 window，都可能噪声或泄密。Tool 定义和结果常常比用户消息更长。

### Level 3 — Engineering

Context Engineering 的工作是决定这一步放什么、以什么顺序、用什么预算。这比「写一个更好的 prompt」更大。
