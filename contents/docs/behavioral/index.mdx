准备 8–10 个故事，覆盖：冲突、失败、领导力、模糊需求、技术判断、跨团队。

## 故事卡片

### 示例：推动一次模糊需求落地

- **S** 背景：谁、什么时候、为什么难
- **T** 你的职责，不是「我们」
- **A** 你做的 3 个具体动作
- **R** 可量化结果 + 你学到什么

把真实项目填进上面的结构。不要写得像年终总结。
