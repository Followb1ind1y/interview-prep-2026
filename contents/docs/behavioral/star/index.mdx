每条都能讲 2 分钟，也能压到 45 秒。从 Tier 1 项目抽，不要另编一套与简历无关的经历。

面试官喜欢：*It didn’t work initially. Here’s how I diagnosed it.*

## 模板

- **S** 背景：谁、什么时候、为什么难
- **T** 你的职责，不是「我们」
- **A** 你做的 3 个具体动作
- **R** 可量化结果 + 你学到什么
