不要只用一种讲法应付所有人。

| 听众 | RAG 怎么讲 |
| --- | --- |
| 非技术的业务方 | 先找到相关材料，再让模型基于这些材料回答，并说明怎么减少胡编 |
| 资深 ML 工程师 | 切块 / embedding / 混合检索 / 重排 / 评测，以及各自的失败模式 |

Agent、评测、延迟优化也同样准备两层讲法。

## 练习

- 向非技术的业务方解释 RAG。（Explain RAG to a non-technical stakeholder.）
- 向资深 ML 工程师解释 RAG。（Explain RAG to a senior ML engineer.）
- 向招聘经理解释 multi-agent。（Explain multi-agent to a hiring manager.）

</Locale>

<Locale lang="en">

Don't use a single explanation for everyone.

| Audience | How to explain RAG |
| --- | --- |
| Non-technical stakeholder | Find the relevant material first, have the model answer from it, and explain how that cuts down on made-up answers |
| Senior ML engineer | Chunking / embeddings / hybrid search / reranking / evaluation, and how each one fails |

Prepare the same two layers for agents, evaluation, and latency optimization.

## Practice

- Explain RAG to a non-technical stakeholder.
- Explain RAG to a senior ML engineer.
- Explain multi-agent to a hiring manager.
