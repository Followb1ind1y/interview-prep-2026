## 投入分层

- **Tier 1**：5 min 架构 + 10 min 深挖，无稿
- **Tier 2**：架构、贡献、一个权衡
- **Tier 3**（备问，不单独开页）：Sustainability Agent、Negotiation Expert

不再花大量时间做新 demo。

## 每张卡片必答

| 维度 | 问题 |
| --- | --- |
| What | 你做了什么产品？ |
| Why | 为什么要做？ |
| Architecture | 数据怎么流？ |
| Contribution | **你**具体做了哪几块？ |
| Decisions | 为什么 Gemini / LangGraph / multi-agent，而不是 X？ |
| Problems | 哪里坏过？ |
| Trade-offs | 还考虑过什么方案？ |
| Results | 延迟、准确、成本、规模 |
| Reflection | 现在会怎么改？ |

## 本专栏计划

先填满三张 Tier 1，再补 PMI 的 SQL 防护和 Fine-tuning 的 ZeRO / vLLM。
