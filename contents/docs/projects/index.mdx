## 投入分层

- **Tier 1**：5 分钟讲架构 + 10 分钟深挖，不看稿
- **Tier 2**：架构、个人贡献、一个取舍
- **Tier 3**（备用，不单独开页）：Sustainability Agent、Negotiation Expert

不再花大量时间做新的 demo。

## 每张卡片必答

| 维度 | 问题 |
| --- | --- |
| 做了什么 | 你做的是什么产品？ |
| 为什么 | 为什么要做？ |
| 架构 | 数据是怎么流动的？ |
| 个人贡献 | **你** 具体负责了哪几块？ |
| 决策 | 为什么选 Gemini / LangGraph / multi-agent，而不是别的方案？ |
| 问题 | 哪里出过问题？ |
| 取舍 | 还考虑过哪些方案？ |
| 结果 | 延迟、准确率、成本、规模 |
| 反思 | 现在的话会怎么改？ |

## Depth by tier

- **Tier 1**: 5 minutes of architecture + 10 minutes of deep dive, no notes
- **Tier 2**: architecture, contribution, one trade-off
- **Tier 3** (backup only, no dedicated page): Sustainability Agent, Negotiation Expert

No more big time investments in new demos.

## Every card must answer

| Dimension | Question |
| --- | --- |
| What | What product did you build? |
| Why | Why build it? |
| Architecture | How does data flow? |
| Contribution | Which parts did **you** build? |
| Decisions | Why Gemini / LangGraph / multi-agent instead of X? |
| Problems | What broke? |
| Trade-offs | What alternatives did you consider? |
| Results | Latency, accuracy, cost, scale |
| Reflection | What would you change now? |
