## 口述骨架（先填这三张）

### Negotiation Practice

生产级全栈：React + FastAPI + Gemini + WebSocket + MongoDB + JWT + streaming + voice/avatar + eval。对标 *Design a real-time AI negotiation platform.*

### Tariff Agent

```
User → Supervisor → Tariff Expert / Impact Expert
         → Research / Tavily / LangGraph
         → BigQuery → Answer
```

必能答：为什么 multi-agent；ADK vs LangGraph；tool 怎么选、怎么可靠；Web search 与 BigQuery 如何组合；Eval 与 hallucination；最大 failure mode。

### Voice AI

```
Audio → Chunking → Whisper → LLM → Streaming → TTS
```

量化锚点：**1.2s end-to-end**。准备：async、pipelining、batching、streaming、token / network / model latency。
