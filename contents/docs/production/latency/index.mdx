对照 Voice 1.2s。必须能拆，不能只说「模型有点慢」。

## 需要掌握

用户感知：

TTFT + Generation latency = User perceived latency

还要拆：

- model latency
- retrieval / reranker latency
- tool latency
- network latency
- serialization
- cold start

## 机制

```
request
 → gateway
 → retriever
 → rerank
 → LLM prefill (TTFT)
 → LLM decode (TPOT × tokens)
 → tools (maybe loop)
```

## 三级回答

### Level 1 — Definition

延迟是分段之和。流式只改善感知，不减少总计算。

### Level 2 — Mechanism

TTFT 看 prefill 和排队。生成看输出长度。Agent 再乘上循环次数。

### Level 3 — Engineering

优化前先 trace。常见杠杆：缓存、更小模型、少 rerank、并行工具、限制输出 token、避免冷启动。
