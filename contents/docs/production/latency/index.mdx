## 三级回答

### Level 1 — 定义

延迟是各段耗时的总和。流式输出只改善体感，不减少总计算量。

### Level 2 — 机制

首 token 延迟取决于 prefill 和排队。生成耗时取决于输出长度。Agent 还要再乘上循环次数。

### Level 3 — 工程

优化之前先看 trace。常见的杠杆：缓存、换更小的模型、少做重排、并行调用工具、限制输出 token、避免冷启动。

## Three-level answers

### Level 1 — Definition

Latency is the sum of its segments. Streaming only improves how it feels; it doesn't reduce total compute.

### Level 2 — Mechanism

TTFT depends on prefill and queueing. Generation time depends on output length. For an agent, multiply by the number of loop iterations.

### Level 3 — Engineering

Look at a trace before optimizing. Common levers: caching, smaller models, less reranking, parallel tool calls, capping output tokens, avoiding cold starts.
