没有 trace 就无法做 Production Eval 和故障诊断。

## 需要掌握

记录：

- latency
- token usage / cost
- model
- prompt version
- retrieved documents
- tool calls
- errors
- evaluation score

## 机制

```
Request
 ↓
Trace
 ↓
LLM call
 ↓
Retriever
 ↓
Reranker
 ↓
Tool
 ↓
LLM
```

## 三级回答

### Level 1 — Definition

能复盘一次请求为什么慢、贵、错。

### Level 2 — Mechanism

分布式 trace 把子调用串起来。Prompt 必须有版本号。检索文档 id 要能回放。

### Level 3 — Engineering

日志里不要明文密钥和用户隐私。采样高流量，全量存失败。接到 eval 闭环。
