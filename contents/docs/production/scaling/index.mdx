## 三级回答

### Level 1 — Definition

用副本、队列和批处理吃更高流量，同时保护下游。

### Level 2 — Mechanism

检索和 API 层水平扩展。LLM 靠并发配额 + batching。长任务进队列。

### Level 3 — Engineering

限流要区分用户级和租户级。Batching 提高吞吐但可能伤延迟。和 Inference 的 continuous batching 对齐。
