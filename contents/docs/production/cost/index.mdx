## 三级回答

### Level 1 — 定义

LLM 产品的变动成本，主要按 token 数和调用次数计算。

### Level 2 — 机制

输出 token 贵，agent 多步调用会把成本放大。Prompt 缓存、路由、换更小的模型都是降本的杠杆。

### Level 3 — 工程

先算清数量级，再做优化。缓存命中率和路由准确率会直接反映到账单上。面试时要能当场估算。

## Three-level answers

### Level 1 — Definition

The variable cost of an LLM product is driven mainly by token count and number of calls.

### Level 2 — Mechanism

Output tokens are expensive, and multi-step agents multiply the cost. Prompt caching, routing, and smaller models are the main levers.

### Level 3 — Engineering

Get the order of magnitude right before optimizing. Cache hit rate and routing accuracy show up directly on the bill. In an interview, you need to do this math on the spot.

## Interview questions

2. Why are output tokens usually more worth compressing?
3. What do 3 extra agent steps mean for cost?
