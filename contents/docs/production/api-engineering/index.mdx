
## 三级回答

### Level 1 — Definition

LLM 是高延迟、限流、部分失败的 HTTP/RPC 依赖。

### Level 2 — Mechanism

流式降低 TTFT 体感。超时要分连接 / 首 token / 总时长。限流和 backoff 保护你和供应商。

### Level 3 — Engineering

对非幂等工具不要盲目 retry。连接池和 async 决定能否撑 QPS。接到 Voice 的 streaming。
