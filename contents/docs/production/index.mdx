## 本专栏计划

1. API：对照 FastAPI + Gemini 流式输出
2. 延迟：对照 Voice 项目的 1.2s，能拆出首 token / 检索 / 工具各占多少
3. 成本：会算每天 10 万用户时月费的数量级
4. 可观测性 + 可靠性：prompt 版本、token、失败都能追踪
