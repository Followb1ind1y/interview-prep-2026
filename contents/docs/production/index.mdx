## 建议学习顺序与深度

| 页面 | 深度 | 重点 |
| --- | --- | --- |
| [Latency](/docs/production/latency) | 🔴 学透 | prefill / decode、关键路径、排队与尾延迟 |
| [API Engineering](/docs/production/api-engineering) | 🔴 学透 | 错误分类、jitter、重试风暴、幂等键 |
| [Cost](/docs/production/cost) | 🔴 学透 | 月账单手算、agent 成本曲线、单位经济学 |
| [Scaling](/docs/production/scaling) | 🟡 抓要点 | 容量换算、多层限流、扩容信号 |
| [Reliability](/docs/production/reliability) | 🔴 学透 | 熔断 / 隔舱 / 减载、降级阶梯、故障注入 |
| [Observability](/docs/production/observability) | 🟡 抓要点 | trace 字段、告警、事故 → 评估闭环 |

1. **请求先活下来：** Latency → API Engineering。先懂一个 token 怎么来，再写对一个请求。
2. **规模与账单：** Cost → Scaling。手算账单，再把流量换算成并发和供应商配额。
3. **线上有据可查：** Reliability → Observability。系统级容错，再用 trace 与质量信号闭环。

## 本栏约定

- **分工**：API Engineering 管**单个请求**写对；Reliability 管**整个系统**在依赖故障时活下来，两页不重复。
- **贯穿案例**：“喵喵粮仓”客服，订单 `20240915`、政策 `P-17 v3`。示意数字与价格只用于手算，不是个人项目实测或当前报价。
- **练习**：读完一页就用 `/drill production/<页面 slug>` 练，课件生成不计作掌握。
