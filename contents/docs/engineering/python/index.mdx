## Level 0 · 对象与引用

### 赋值是复制吗？

不是。Python 的变量是**名字**，赋值是把名字绑定到对象上。

</Locale>

<Locale lang="en">

## Level 0 · Objects and references

Assignment binds a name to an object; it never copies.

</Locale>

```python
a = [1, 2]
b = a              # b and a name the same list
b.append(3)
print(a)           # [1, 2, 3]

x = 1
y = x
y += 1             # ints are immutable: y is rebound to a new object
print(x)           # 1
```

<Locale lang="zh">

- **不可变对象**（int、str、tuple、frozenset）：“修改”实际是创建新对象并重新绑定。
- **可变对象**（list、dict、set、自定义对象）：原地修改，所有引用它的名字都看得到。
- `==` 比较值，`is` 比较是否是同一个对象。判断 `None` 用 `is None`。

### 可变默认参数为什么是坑？

</Locale>

<Locale lang="en">

Immutable objects (int, str, tuple) are replaced on "modification"; mutable ones (list, dict, set) change in place for every name. `==` compares values, `is` identity; use `is None`.

### Why are mutable defaults a trap?

</Locale>

```python
def add_message(msg, history=[]):     # the default list is created ONCE, at definition time
    history.append(msg)
    return history

add_message("hi")      # ['hi']
add_message("bye")     # ['hi', 'bye']  <- shared across calls!

def add_message_fixed(msg, history=None):
    if history is None:
        history = []
    history.append(msg)
    return history
```

<Locale lang="zh">

默认值在**函数定义时**只计算一次。在 agent 代码里，如果把对话历史写成可变默认参数，**不同用户的对话会串在一起**——这是真实的线上事故类型。

### 浅拷贝与深拷贝

`copy.copy` / `list(x)` / `x[:]` 只复制外层容器，内层对象仍共享；`copy.deepcopy` 递归复制。例：复制一份 messages 列表给另一个 agent 修改，如果用浅拷贝，修改其中某条消息的 dict 会影响原列表。

<Locale lang="en">

Defaults are evaluated once at definition; a mutable default history in agent code can mix different users' conversations — a real incident class. Shallow copies (`copy.copy`, `list(x)`, `x[:]`) share inner objects; `deepcopy` recurses — editing a message dict in a shallow-copied list changes the original.

## Level 1 · dict 与 set

### 为什么查找是 O(1)？

dict 和 set 是**哈希表**：对键调用 `hash()` 得到一个整数，映射到数组的某个槽位，直接定位。平均 O(1)；大量哈希冲突时退化（Python 的实现会在负载过高时扩容，保持冲突少）。

### 什么能当键？

**可哈希**的对象：哈希值在生命周期内不变。不可变的内置类型都可以；list、dict、set 不行（内容可变，哈希会变）。tuple 只有在所有元素都可哈希时才可哈希。这就是 [数组与哈希](/docs/algorithms/arrays) 里“字母异位词分组”要用 `tuple(sorted(w))` 而不是 `sorted(w)` 作键的原因。

### 顺序

Python 3.7 起 dict 保证**保持插入顺序**（语言规范）；set 不保证顺序。

## Level 1 · dict and set

Hash tables: `hash(key)` locates a slot directly — O(1) on average, with resizing to limit collisions. Keys must be hashable (stable hash for their lifetime): immutable built-ins yes; list, dict, set no; tuples only if all elements are hashable — hence `tuple(sorted(w))` in anagram grouping. Dicts preserve insertion order since 3.7; sets don't.

## Level 2 · 迭代器与生成器

### 迭代器协议

`for x in obj` 实际上调用 `iter(obj)` 得到迭代器，然后反复 `next()`，直到抛出 `StopIteration`。

### 生成器：`yield` 怎么工作？

含有 `yield` 的函数调用后**不立即执行**，而是返回一个生成器对象。每次 `next()`，函数执行到下一个 `yield`，交出一个值并**暂停**（保留局部变量），下次从暂停处继续。

</Locale>

<Locale lang="en">

## Level 2 · Iterators and generators

`for` calls `iter()` then `next()` until `StopIteration`. A function containing `yield` returns a generator without running; each `next()` runs to the next `yield`, hands out a value, and pauses with its locals intact.

</Locale>

```python
def read_chunks(path: str, size: int = 1024):
    with open(path, "rb") as f:
        while chunk := f.read(size):
            yield chunk                 # pause here; memory stays O(size), not O(file)

squares = (x * x for x in range(10**9))   # generator expression: nothing computed yet
next(squares)                              # 0

# Streaming an LLM response from FastAPI is the same idea:
# async def stream():
#     async for token in model_stream(prompt):
#         yield f"data: {token}\n\n"
# return StreamingResponse(stream(), media_type="text/event-stream")
```

<Locale lang="zh">

为什么重要：

- **惰性**：不一次性生成全部数据，内存只占当前一项——处理大文件、长数据流必备。
- **流式输出**：LLM 的流式响应就是一个（异步）生成器，一边从模型拿 token 一边 `yield` 给客户端（见 [API Engineering](/docs/production/api-engineering) Level 1）。
- 生成器**只能遍历一次**：遍历完再遍历是空的——常见 bug。

列表推导式 `[...]` 立即生成整个列表；生成器表达式 `(...)` 惰性。数据很大时用后者。

<Locale lang="en">

Generators are lazy (memory holds one item — essential for big files and streams), they power streaming LLM responses (an async generator yielding tokens to `StreamingResponse`), and they can be consumed only once — a common bug. List comprehensions build everything now; generator expressions are lazy.

## Level 3 · 装饰器与上下文管理器

### 装饰器的本质

装饰器就是“**接收一个函数、返回一个新函数**”的函数；`@timer` 等价于 `f = timer(f)`。它依赖**闭包**：内层函数记住了外层函数的变量。

</Locale>

<Locale lang="en">

## Level 3 · Decorators and context managers

A decorator takes a function and returns a new one (`@timer` means `f = timer(f)`), relying on closures that remember outer variables.

</Locale>

```python
import functools
import time

def timer(fn):
    @functools.wraps(fn)                         # keep fn.__name__, __doc__ for logs/tracing
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        try:
            return fn(*args, **kwargs)
        finally:
            print(f"{fn.__name__} took {time.perf_counter() - start:.3f}s")
    return wrapper

def retry(times: int):                           # parameterized: a factory returning a decorator
    def decorator(fn):
        @functools.wraps(fn)
        def wrapper(*args, **kwargs):
            for attempt in range(times):
                try:
                    return fn(*args, **kwargs)
                except TimeoutError:
                    if attempt == times - 1:
                        raise
        return wrapper
    return decorator
```

<Locale lang="zh">

- **带参数的装饰器**多一层：`@retry(3)` 先调用 `retry(3)` 得到真正的装饰器。完整的异步重试实现见 [AI 实用编码题](/docs/algorithms/ml-coding) Level 1。
- 你用过的装饰器：FastAPI 的 `@app.get`、`functools.cache`、LangChain / LangGraph 的 `@tool`——它们都是在不改函数体的前提下给函数加行为（注册路由、缓存、生成工具 schema）。

### 上下文管理器：`with` 做了什么？

`with obj as x:` 调用 `obj.__enter__()`，代码块结束（**包括抛异常**）时调用 `__exit__()`。用于保证资源释放：文件、锁、数据库连接、HTTP 客户端。

</Locale>

<Locale lang="en">

Parameterized decorators add a layer (`@retry(3)` builds the decorator first); the async version is in [AI Practical Coding](/docs/algorithms/ml-coding). Familiar decorators — FastAPI's `@app.get`, `functools.cache`, LangChain's `@tool` — add behavior (routing, caching, tool schemas) without changing the body. `with` calls `__enter__` and guarantees `__exit__` even on exceptions — files, locks, connections, clients.

</Locale>

```python
from contextlib import contextmanager

@contextmanager
def span(name: str):
    start = time.perf_counter()
    try:
        yield                                   # the with-block runs here
    finally:
        print(f"{name}: {time.perf_counter() - start:.3f}s")   # runs even on errors

with span("retrieve"):
    ...
```

## Level 4 · 类型与数据建模

### type hints 在运行时检查吗？

**不检查**。`def f(x: int)` 传入字符串照样运行；类型标注给 IDE 和静态检查器（mypy、pyright）用。要在运行时校验，需要 Pydantic 这类库。

### dataclass 还是 Pydantic？

| | `dataclass` | Pydantic `BaseModel` |
| --- | --- | --- |
| 作用 | 自动生成 `__init__`、`__repr__`、`__eq__` | 同上 + **运行时校验与类型转换** |
| 校验 | 无 | 有：类型不对报错，`"5"` 可转成 5 |
| 序列化 | 需要自己写 | `model_dump()` / `model_dump_json()`，可生成 JSON Schema |
| 适用 | 内部数据结构 | **系统边界**：API 请求 / 响应、LLM 结构化输出、配置 |

LLM 应用里 Pydantic 无处不在：FastAPI 用它校验请求；用它定义 schema 生成 LLM 的结构化输出格式，并校验模型返回的 JSON（见 [Structured Output](/docs/application/structured-output)）；工具调用的参数 schema 也常从 Pydantic 模型生成。

</Locale>

<Locale lang="en">

## Level 4 · Types and data modeling

Type hints aren't checked at runtime; mypy and pyright use them statically. Dataclasses generate boilerplate for internal structures; Pydantic adds runtime validation, coercion, serialization, and JSON Schema — use it at boundaries: API requests and responses, LLM structured outputs ([Structured Output](/docs/application/structured-output)), tool argument schemas, config.

</Locale>

```python
from pydantic import BaseModel, Field

class RefundDecision(BaseModel):
    order_id: str
    eligible: bool
    amount: float = Field(ge=0)            # validated at runtime
    reason: str

RefundDecision.model_json_schema()          # feed to the LLM as the output schema
RefundDecision.model_validate_json('{"order_id": "20240915", "eligible": false, "amount": 0, "reason": "in transit"}')
```
