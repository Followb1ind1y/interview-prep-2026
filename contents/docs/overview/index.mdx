目标不是重新学一遍 AI，而是把已有 **3+ 年 LLM 工程经验** 转成 Interview Performance。

不要把 70% 时间花在「学习知识」、只留 30% 给面试。后期默认：

**30% 学习 + 30% 项目深挖 + 20% Coding + 20% Mock**

拿到面试以后再调成：**20% 学习 + 20% Coding + 30% Project/Design + 30% Mock**。

<Note title="每天只记 6 件事">
定位：找什么工作。简历：怎么让别人愿意见我。项目：怎么证明做过。技术：到底懂不懂。编码：能不能写。面试：压力下能不能讲出来。
</Note>

## 知识存在哪

站点三块内容职责不同。同一件事不要写三遍：对外成品、可复用答案、单次流程各放一处。

```
contents/
  docs/          可复用的面试答案（概念、项目深挖、STAR、题型）
  resume/        对外成品（About、CV、PDF）
  companies/     单次流程（这家公司、这个 JD、这一轮问了什么）
  site/          首页展示（简介、时间线、Roadmap）
notes/           未上站草稿；Inbox 会话不上 git、不上网站
```

| 内容 | Docs | Resume | Companies |
| --- | --- | --- | --- |
| Target Job Profile | **主本** | 只反映定稿后的 headline | 不写总定位 |
| 30s / 60s / 2min 开场 | 排练稿在 [定位](/docs/positioning) | About 是对外叙述 | 不写 |
| 简历 bullet | 不写长文 | **主本**（`lib/resume-data.ts` + PDF） | 可针对 JD 改一版备注 |
| LinkedIn | 不镜像全文 | 与 CV 叙事对齐即可 | 不写 |
| 项目架构 / 权衡 / 失败 | **主本** | 1–2 条结果导向 bullet | 只记「这家追问了哪一段」 |
| RAG / Agent / Inference | **主本** | 技能关键词 | 不写通用定义 |
| LeetCode / SQL 模板 | **主本** | 不写 | 只记「这轮考了哪题」 |
| STAR / 行为题 | **主本** | 不写完整故事 | 只记该公司特有的 Why us |
| 投递状态、轮次、薪资谈判 | 不上站细账 | 不写 | **主本** |
| Mock 复盘 | Journal 一行索引 → 回填知识页 | 不写 | 若针对某公司，记在该公司页 |

<Note title="一条知识一个主本">
Docs 写到能脱稿讲。Resume 只保留 recruiter 会扫的那一层。Companies 只保留「这一家、这一轮」才有意义的信息。Mock 暴露的缺口，回填到对应知识页，不要堆在日志里。
</Note>

## 怎么往站点里写

每天只做一件事：**打开对应目录，更新或新增一篇 `index.mdx`。** 刷新后笔记、搜索和首页热力图会跟上。

新页面还要在 `settings/documents.ts`（或 companies / resume）里加导航项。

`date` 会点亮首页当月的小方块。同一天更新越多，颜色越深。

首页三个开关：`contents/site/profile.json`、`timeline.json`、`roadmap.json`。
