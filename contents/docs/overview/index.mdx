每天只需要做一件事：**打开对应目录，更新或新增一篇 `index.mdx`。** 刷新网站后，笔记、搜索和首页热力图都会跟上。

<Note title="工作流">
先改 Markdown，再在时间线 JSON 里补一行当天做了什么。不需要改页面代码。
</Note>

## 文件放哪里

```
contents/
  docs/          面试知识点
  companies/     投递记录
  resume/        简历与介绍
  site/
    profile.json     首页自我介绍
    timeline.json    首页时间线
    roadmap.json     底部计划
```

每一篇文档都是一个文件夹 + `index.mdx`：

```
contents/docs/algorithms/arrays/index.mdx
```

同时在 `settings/documents.ts`（或 companies / resume）里补上导航项，侧边栏才会出现新页面。

## Frontmatter

```md
---
title: 数组与哈希
titleEn: Arrays & Hashing
description: 双指针、哈希表、前缀和。
date: 2026-08-30
keywords: ["array", "hash"]
---
```

`date` 会点亮首页当月的小方块。同一天更新越多，颜色越深。

## 首页三个开关

| 文件 | 作用 |
| --- | --- |
| `contents/site/profile.json` | 主页名字、角色、简介 |
| `contents/site/timeline.json` | 滚动时间线 |
| `contents/site/roadmap.json` | Plan / Roadmap |
