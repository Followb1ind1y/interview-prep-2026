## 机制

```
Prefill
Prompt → parallel computation → KV Cache

Decode
Token → KV Cache → Next Token → KV Cache update → Next Token
```

## 三级回答

### Level 1 — Definition

推理分两段：prefill 吃完整 prompt，decode 一个一个吐 token。

### Level 2 — Mechanism

KV cache 避免 decode 时重算历史 K/V。Batching 把多个请求拼在一起提高 GPU 利用率；continuous batching 让请求随时进出。Quantization 降精度换显存和吞吐。

### Level 3 — Engineering

TTFT 主要看 prefill；用户打字感主要看 TPOT。KV cache 随 batch × layers × seq × dim 涨，长会话会先爆显存。vLLM / PagedAttention 解决碎片化。FlashAttention 是算子层的 IO 优化，不是另一种模型。
