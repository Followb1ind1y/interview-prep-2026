## 三级回答

### Level 1 — 定义

推理分两段：prefill 一次性处理完整个 prompt，decode 一个一个地输出 token。

### Level 2 — 机制

KV cache 避免 decode 时重算历史 token 的 K/V。Batching 把多个请求拼在一起，提高 GPU 利用率；continuous batching 让请求随时进出。量化降低数值精度，换取显存和吞吐。

### Level 3 — 工程

TTFT 主要看 prefill；用户感受到的「打字速度」主要看 TPOT。KV cache 随 batch × 层数 × 序列长度 × 维度增长，长会话会先把显存撑爆。vLLM / PagedAttention 解决的是显存碎片化。FlashAttention 是算子层面的 IO 优化，不是另一种模型。

## Three-level answers

### Level 1 — Definition

Inference has two phases: prefill processes the entire prompt at once, and decode emits tokens one at a time.

### Level 2 — Mechanism

The KV cache avoids recomputing K/V for earlier tokens during decode. Batching packs multiple requests together to raise GPU utilization; continuous batching lets requests join and leave at any step. Quantization lowers numeric precision in exchange for memory and throughput.

### Level 3 — Engineering

TTFT is mostly about prefill; the typing speed users feel is mostly TPOT. The KV cache grows with batch × layers × sequence length × hidden size, so long sessions run out of GPU memory first. vLLM / PagedAttention fix memory fragmentation. FlashAttention is an IO-aware kernel optimization, not a different model.
