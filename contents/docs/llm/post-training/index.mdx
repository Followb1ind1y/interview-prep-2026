```
Pretraining
     ↓
SFT
     ↓
Preference Optimization
     ↓
RLHF / DPO
     ↓
Instruction Following
```

## 三级回答

### Level 1 — Definition

Post-training 把「会续写」变成「会按指令做、偏好人类认可的回答」。

### Level 2 — Mechanism

SFT 教格式和任务。RLHF 用 reward model + RL；DPO 直接在偏好对上优化，省掉显式 RM 采样。

### Level 3 — Engineering

数据质量和偏好覆盖决定行为。Fine-tune 过猛会 catastrophic forgetting。生产里多数能力用 RAG / prompt，而不是再训一遍基座。
