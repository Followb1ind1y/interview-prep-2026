## 需要掌握

- multilingual tokenization
- prompt 中 token 数估算

## 机制

```
text → tokenizer → token ids → embedding
```

同一段话，中文和代码通常比英文吃更多 token。

## 三级回答

### Level 1 — Definition

Tokenizer 把文本切成模型认识的离散单元。计费和 context 都按 token，不按 word。

### Level 2 — Mechanism

BPE / WordPiece 用子词平衡词表大小和 OOV。SentencePiece 直接在 raw text 上训，适合多语言。

### Level 3 — Engineering

Prompt 越长，prefill 越慢、KV cache 越大、费用越高。中文 / 代码场景要单独估 token，不能按英文词数换算。
