## 三级回答

### Level 1 — 定义

Attention 让每个 token 按相关性去聚合其他 token 的信息。

### Level 2 — 机制

Q 负责提问，K 负责被匹配，V 是被加权取出的内容。Causal mask 禁止看到未来的 token。多个头在不同子空间里并行做这件事。

### Level 3 — 工程

序列长度为 n 时，QKᵀ 是 n×n 的矩阵。长上下文之所以贵，是因为计算量和 KV cache 都随 n 增长。MQA / GQA 减少 K/V 的头数，用一点质量换吞吐和显存。

## Three-level answers

### Level 1 — Definition

Attention lets each token pull in information from other tokens, weighted by how relevant they are.

### Level 2 — Mechanism

Q asks the question, K is what gets matched against, and V is what gets pulled out by weight. The causal mask stops a token from seeing the future. Multiple heads do this in parallel across different subspaces.

### Level 3 — Engineering

With sequence length n, QKᵀ is an n×n matrix. Long context gets expensive because both compute and the KV cache grow with n. MQA and GQA cut the number of K/V heads, trading a little quality for throughput and memory.
