## 机制

```
Q = X Wq
K = X Wk
V = X Wv
scores = Q Kᵀ / √d     →  O(n²)
weights = softmax(scores + causal mask)
output = weights V
```

## 三级回答

### Level 1 — Definition

Attention 让每个 token 按相关性聚合其他 token 的信息。

### Level 2 — Mechanism

Q 问、K 被匹配、V 被加权取出。Causal mask 禁止看未来。多头并行不同子空间。

### Level 3 — Engineering

序列长 n 时，QKᵀ 是 n×n。长上下文变贵，是因为计算和 KV cache 都随 n 涨。MQA / GQA 减少 K/V 头数，换吞吐和显存。
