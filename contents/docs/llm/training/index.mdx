- pretraining

## 机制

```
prefix tokens → predict next token
             → cross entropy loss
             → backprop → update weights
```

## 三级回答

### Level 1 — Definition

预训练是大规模 next-token prediction，让模型学会语言和世界知识的统计结构。

### Level 2 — Mechanism

每个位置预测下一个 token，loss 是交叉熵。数据、模型、算力按 scaling laws 一起涨。

### Level 3 — Engineering

面试不要展开优化器论文。能说清：预训练给的是通用先验；任务能力和听话来自 post-training。
