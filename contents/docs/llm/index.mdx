## 本专栏计划

1. Tokenization：token 数为什么比 word 数重要；中文 / code 为什么更贵
2. Transformer + Attention：能画 block，能讲 MHA / MQA / GQA
3. Training 点到为止；Post-training 必须熟
4. Fine-tuning 对照 LLaMA + QLoRA；先答 RAG vs FT
5. Inference 比想象中更深：TTFT、KV cache、continuous batching、tokens/sec
