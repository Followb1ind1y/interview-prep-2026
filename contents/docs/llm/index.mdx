## 本专栏计划

1. Tokenization：token 数为什么比词数重要；中文和代码为什么更贵
2. Attention & Transformer：从 encoder / decoder 学到 decoder-only，能画出 block，能讲 KV cache 和 MHA / MQA / GQA
3. Training 点到为止；Post-training 必须熟
4. Fine-tuning 对照 LLaMA + QLoRA 项目；先答清 RAG 和微调怎么选
5. Inference 比想象中更深：TTFT、KV cache、continuous batching、tokens/sec
