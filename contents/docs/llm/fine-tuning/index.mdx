## 机制

```
Prompt Engineering  →  不改权重，改输入
RAG                 →  不改权重，改上下文
Fine-tuning         →  改权重（或低秩适配器）
```

## 三级回答

### Level 1 — 定义

Fine-tuning 用领域数据继续训练，改变模型权重（或插入的 adapter）。

### Level 2 — 机制

LoRA 冻结基座模型，只训练低秩矩阵。QLoRA 先把基座量化，再做 LoRA，进一步降低显存。PEFT 是这类方法的总称。

### Level 3 — 工程

知识会变、需要引用来源 → RAG。格式 / 语气 / 工具使用习惯要稳定 → 小规模 SFT / LoRA。只是换个说法 → prompt。三者经常组合使用，不是单选题。

You need to be able to choose between the three ways of changing model behavior, and tie the choice back to the LLaMA project.

## Must know

- full fine-tuning
- LoRA
- QLoRA
- PEFT
- adapters

## Mechanism

```
Prompt Engineering  →  weights unchanged, change the input
RAG                 →  weights unchanged, change the context
Fine-tuning         →  change the weights (or a low-rank adapter)
```

## Three-level answers

### Level 1 — Definition

Fine-tuning keeps training on domain data, which changes the model's weights (or an inserted adapter).

### Level 2 — Mechanism

LoRA freezes the base model and trains small low-rank matrices. QLoRA quantizes the base model first and then applies LoRA, cutting memory further. PEFT is the umbrella term for this family of methods.

### Level 3 — Engineering

Knowledge that changes or needs citations → RAG. Format, tone, or tool-use habits that need to be consistent → small-scale SFT / LoRA. Just phrasing things differently → prompting. They're usually combined; it's not a multiple-choice question.
