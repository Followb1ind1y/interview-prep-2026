## 机制

```
Prompt Engineering  →  不改权重，改输入
RAG                 →  不改权重，改上下文
Fine-tuning         →  改权重（或低秩适配器）
```

## 三级回答

### Level 1 — Definition

Fine-tuning 用领域数据继续训练，改变模型权重（或插入的 adapter）。

### Level 2 — Mechanism

LoRA 在冻结基座上训低秩矩阵。QLoRA 把基座量化后再 LoRA，降显存。PEFT 是这类方法的总称。

### Level 3 — Engineering

知识会变、要引用 → RAG。格式 / 语气 / 工具习惯稳定 → 小规模 SFT / LoRA。只是换说法 → prompt。三者常组合，不是单选题。
