## 三级回答

### Level 1 — Definition

迫使模型输出可解析、可校验的结构，而不是自由文本。

### Level 2 — Mechanism

JSON mode / constrained decoding 降低语法错误。应用侧仍要用 schema（Pydantic）校验字段类型和必填项。失败则 retry 或降级。

### Level 3 — Engineering

Schema 越严，下游越稳，但复杂嵌套会增加失败率。校验失败不要死循环 retry。Tool calling 的参数校验是同一模式。
