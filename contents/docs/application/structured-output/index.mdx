## 三级回答

### Level 1 — 定义

强制模型输出可解析、可校验的结构，而不是自由文本。

### Level 2 — 机制

JSON mode / 约束解码能减少语法错误。但应用侧仍要用 schema（Pydantic）校验字段类型和必填项。校验失败就重试或降级。

### Level 3 — 工程

Schema 越严，下游越稳，但复杂的嵌套结构会提高失败率。校验失败时不要无限重试。Tool calling 的参数校验也是同一个模式。

## Three-level answers

### Level 1 — Definition

Forcing the model to produce a structure you can parse and validate, instead of free text.

### Level 2 — Mechanism

JSON mode and constrained decoding cut down on syntax errors. The application still validates field types and required fields against a schema (Pydantic). On failure, retry or fall back.

### Level 3 — Engineering

The stricter the schema, the more stable everything downstream — but deeply nested structures raise the failure rate. Never retry forever on validation errors. Tool-call argument validation follows exactly the same pattern.
