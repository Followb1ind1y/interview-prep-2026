Routing 是成本和质量的杠杆，也是 Production 的入口。

## 需要掌握

- routing
- fallback
- model cascade
- A/B testing

## 机制

```
Easy query        → cheap model
Hard query        → strong model
Coding            → specialized model
Summarization     → cheap model
```

## 三级回答

### Level 1 — Definition

按请求特征把流量分到不同模型。

### Level 2 — Mechanism

可用规则（长度、任务类型）或小分类器 / 小模型先判断难度。Cascade：先便宜模型，置信度低再升级。

### Level 3 — Engineering

误路由会把简单问题打贵、把难题打崩。必须有 fallback 和 A/B。和 Agent 的 tool 选择不同：这里选的是「哪个脑」，不是「哪个工具」。
