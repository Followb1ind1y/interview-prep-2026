Prompt 是 context 的一部分，但先把这一层讲清楚，再进入 Context Engineering。

## 需要掌握

- zero-shot / few-shot
- role prompting
- structured prompting
- XML / JSON
- output constraints
- instruction hierarchy
- examples
- prompt templates

## 机制

```
System / developer instructions
        ↓
User task
        ↓
Examples / schema
        ↓
Output contract
```

## 三级回答

### Level 1 — Definition

用自然语言规定任务、约束和输出形状。

### Level 2 — Mechanism

Instruction hierarchy 决定 system 和 user 冲突时听谁。Few-shot 用例子锁格式。XML / JSON 标签让模型更容易定位指令和数据。

### Level 3 — Engineering

生产里 prompt 要版本化、模板化，并和 structured output 一起用。长 prompt 的成本与丢失中间信息，转到 Context Engineering。
