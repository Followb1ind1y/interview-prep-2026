## 三级回答

### Level 1 — 定义

用自然语言规定任务、约束和输出的形状。

### Level 2 — 机制

指令优先级决定 system 和 user 冲突时听谁的。Few-shot 用例子锁定格式。XML / JSON 标签让模型更容易分清哪部分是指令、哪部分是资料。

### Level 3 — 工程

生产环境里 prompt 要版本化、模板化，并和结构化输出一起用。长 prompt 带来的成本和中间信息丢失问题，放到 Context Engineering 里讲。

## Three-level answers

### Level 1 — Definition

Using natural language to specify the task, its constraints, and the shape of the output.

### Level 2 — Mechanism

The instruction hierarchy decides who wins when system and user instructions conflict. Few-shot examples lock in the format. XML / JSON tags make it easier for the model to tell instructions apart from data.

### Level 3 — Engineering

In production, prompts are versioned, templated, and paired with structured output. The cost of long prompts and the lost-in-the-middle problem belong to Context Engineering.
