能做 trade-off，而不是背一个「最强模型」。

## 需要掌握

从下面几维比较：

- quality
- latency
- cost
- context
- tool calling
- structured output
- multimodal
- reliability

## 机制

```
Task requirements
        ↓
quality × latency × cost × tools × context
        ↓
Primary model + fallback
```

## 三级回答

### Level 1 — Definition

按任务选模型，而不是按品牌。

### Level 2 — Mechanism

同一任务可在便宜模型和强模型之间测。工具、结构化、长上下文、多模态支持是硬约束。

### Level 3 — Engineering

你的项目里为什么是 Gemini：企业生态、BigQuery、延迟还是质量？要能说出备选 Claude / GPT 会在哪一维更好。
