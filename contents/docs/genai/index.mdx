## LLM Fundamentals

Transformer · Attention · Training · Fine-tuning · Inference

- Self-attention / MHA / QKV / 位置编码 / Causal / Encoder vs Decoder
- Pretraining → SFT → RLHF / DPO
- LoRA / QLoRA / 量化 / DeepSpeed ZeRO / gradient checkpointing
- KV cache、continuous batching、speculative decoding、vLLM / PagedAttention

简历写了 Fine-tuning 和 vLLM，这两块必须经得起追问。

## RAG

Embedding · Retrieval · Reranking · Hybrid Search · Evaluation

```
Documents → Parsing → Chunking → Embedding → Vector DB
         → Retriever → Reranker → Context → LLM → Answer
```

必会：BM25、dense、hybrid、RRF、metadata filter、query rewrite。项目锚点：**FAISS + BM25 + RRF**。

## Agent

Tool Calling · Planning · Memory · Multi-Agent · Reliability

- Workflow = 预定义路径；Agent = 动态决策
- Multi-agent 有用，是因为不同任务需要不同 tools / instructions / reasoning；代价是延迟、协调、更多失败模式
- Failure modes：幻觉 tool call、错参、死循环、context pollution、部分失败
- Reliability：schema、validation、retry、timeout、fallback、observability、DeepEval
