## 模式

- 用 dummy head（哑节点）处理头节点的边界情况
- 快慢指针找中点 / 判断环
- 反转一段区间时，记清 `pre / cur / next` 三个指针

## Patterns

- A dummy head handles edge cases at the head node
- Fast and slow pointers find the middle or detect a cycle
- When reversing a sub-range, keep `pre / cur / next` straight
