## Level 0 · Dummy nodes and merging

When the result's head is uncertain (merging, deleting), start from a dummy node and return `dummy.next`.

</Locale>

```python
def merge_two_lists(a: ListNode | None, b: ListNode | None) -> ListNode | None:
    dummy = tail = ListNode()
    while a and b:
        if a.val <= b.val:
            tail.next, a = a, a.next
        else:
            tail.next, b = b, b.next
        tail = tail.next
    tail.next = a or b            # append the remainder
    return dummy.next
```

## Level 1 · In-place reversal

</Locale>

```python
def reverse_list(head: ListNode | None) -> ListNode | None:
    prev, cur = None, head
    while cur:
        nxt = cur.next        # 1. remember the rest
        cur.next = prev       # 2. reverse this link
        prev, cur = cur, nxt  # 3. advance
    return prev
```

<Locale lang="zh">

手推 `1 → 2 → 3`：

| 步 | prev | cur | 已反转部分 |
| --- | --- | --- | --- |
| 开始 | None | 1 | — |
| 1 | 1 | 2 | 1 → None |
| 2 | 2 | 3 | 2 → 1 → None |
| 3 | 3 | None | 3 → 2 → 1 → None |

**第 1 步必须先保存 `nxt`**，否则改了 `cur.next` 就找不到后面的节点了。变体：反转链表 II（92，反转一段区间）、K 个一组翻转（25）、回文链表（234：找中点 + 反转后半段 + 比较）。

</Note>

## Level 2 · Fast and slow pointers

</Locale>

```python
def middle_node(head: ListNode) -> ListNode:
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
    return slow                       # second middle for even lengths

def has_cycle(head: ListNode | None) -> bool:
    slow = fast = head
    while fast and fast.next:
        slow, fast = slow.next, fast.next.next
        if slow is fast:              # fast laps slow inside a cycle
            return True
    return False

def remove_nth_from_end(head: ListNode, n: int) -> ListNode | None:
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n + 1):
        fast = fast.next              # gap of n nodes between slow and fast
    while fast:
        slow, fast = slow.next, fast.next
    slow.next = slow.next.next        # slow is just before the target
    return dummy.next
```

<Locale lang="zh">

- **中点**：快指针走到尾时，慢指针在中间。
- **判环（Floyd）**：有环时快指针每步比慢指针多走 1，一定会在环内追上。找环的入口（142）：相遇后，一个指针回到头，两者都每次走一步，再次相遇处就是入口。
- **倒数第 n 个**：先让快指针领先 n+1 步，两者同速前进，快指针到尾时慢指针正好在目标的前一个。用哑节点处理“删除头节点”的情况。

<Note title="自测：到这里你应该能回答">

1. 为什么有环时快慢指针一定会相遇？
2. 删除倒数第 n 个节点时，为什么快指针要领先 n+1 步而不是 n 步？

</Note>

</Locale>

<Locale lang="en">

Middle: slow is mid when fast ends. Floyd: fast gains one node per step and must catch slow inside a cycle; for the entry (142), reset one pointer to head and advance both by one. k-th from end: lead by n+1 so slow stops just before the target; the dummy handles deleting the head.

## 陷阱

<Note type="warning" title="常见错误">

- 反转时没先保存 `next`。
- 访问 `fast.next.next` 前没检查 `fast.next`。
- 删除头节点没用哑节点。
- 不画图直接写。

</Note>
