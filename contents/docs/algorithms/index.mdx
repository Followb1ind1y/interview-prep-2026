## 怎么练

1. **先读模式**：每页每个 Level 先看“信号 → 模板 → 手推”。
2. **限时自己写**：Medium 题 25 分钟内，写不出就看模板，第二天重写一遍。
3. **出声讲**：按每页的讲题顺序——复述题目与约束 → 暴力解与复杂度 → 关键观察 → 写代码 → 手推例子与边界 → 总结复杂度。
4. **记录**：在每页底部的表格记下日期、用时、是否一次通过、卡在哪；一周后重做卡住的题。

每页的参考实现都已实际运行验证。用 `/drill algorithms/<页面 slug>` 让我出题并追问。

## Roadmap (~6 weeks, 1–2 problems a day)

Week 1 arrays & hashing 🔴; week 2 binary search/heaps 🔴 + stacks 🟡; week 3 linked lists 🟡 + trees 🔴; week 4 graphs 🔴 + backtracking 🟡; week 5 DP 🟡; week 6 AI practical coding 🔴. Short on time: arrays → trees → graphs → AI practical coding.

## How to practice

Read signal → template → trace; write it yourself in 25 minutes; talk it through (restate, brute force, key insight, code, trace, complexity); log each attempt and redo misses a week later. All reference code has been run. Use `/drill algorithms/<page slug>` for mock rounds.
