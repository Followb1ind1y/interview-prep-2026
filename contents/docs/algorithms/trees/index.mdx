## Level 0 · 递归思维

### 递归三问

1. **这个函数对一个子树返回什么？**
2. **怎么用左右子树的返回值算出当前节点的返回值？**
3. **空节点返回什么？**

最大深度：返回“子树深度”；当前深度 = 1 + max(左, 右)；空节点返回 0。

</Locale>

<Locale lang="en">

## Level 0 · Recursive thinking

Ask: what does the function return for a subtree, how do children's results combine, and what does an empty node return? Max depth: returns subtree depth; 1 + max(left, right); empty is 0.

</Locale>

```python
def max_depth(root: TreeNode | None) -> int:
    if not root:
        return 0
    return 1 + max(max_depth(root.left), max_depth(root.right))
```

<Locale lang="zh">

### 返回值和全局答案不是一回事

二叉树的直径（543）：最长路径可能**不经过根**。对每个节点，经过它的最长路径 = 左深度 + 右深度；但它**返回给父节点的**只能是一条链：1 + max(左深度, 右深度)。所以用一个外部变量记录全局最大值：

</Locale>

<Locale lang="en">

### Return value vs global answer

Diameter (543): the longest path through a node is left depth + right depth, but a node can only return one branch to its parent (1 + max). Track the global best separately.

</Locale>

```python
def diameter_of_binary_tree(root: TreeNode | None) -> int:
    best = 0
    def depth(node: TreeNode | None) -> int:
        nonlocal best
        if not node:
            return 0
        l, r = depth(node.left), depth(node.right)
        best = max(best, l + r)          # path through this node (global answer)
        return 1 + max(l, r)             # what the parent can use (one branch)
    depth(root)
    return best
```

<Locale lang="zh">

二叉树中的最大路径和（124）是同一个结构，只是把“深度”换成“路径和”，并对负数的子树取 `max(0, …)`。**这是树题里最重要的一个模式**，面试常考。

## Level 1 · 层序遍历

按层处理（层序输出、右视图、每层平均值）用 BFS：**每轮循环先记下当前层的节点数**，只处理这么多。

</Locale>

<Locale lang="en">

## Level 1 · Level order

For per-level work (level order, right side view, averages), BFS and record the current level size before processing it.

</Locale>

```python
from collections import deque

def level_order(root: TreeNode | None) -> list[list[int]]:
    if not root:
        return []
    res, q = [], deque([root])
    while q:
        level = []
        for _ in range(len(q)):          # exactly the nodes of this level
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res
```

## Level 2 · 二叉搜索树

BST：左子树所有值 < 节点 < 右子树所有值。推论：**中序遍历得到有序序列**。

验证 BST 的常见错误：只比较节点和它的直接子节点。`[5, 4, 6, null, null, 3, 7]` 中 3 在 5 的右子树里却小于 5——必须**向下传递上下界**：

</Locale>

<Locale lang="en">

## Level 2 · Binary search trees

Left subtree < node < right subtree, so inorder is sorted. Validating only against direct children fails (3 in the right subtree of 5); pass bounds down.

</Locale>

```python
def is_valid_bst(root: TreeNode | None, lo=float('-inf'), hi=float('inf')) -> bool:
    if not root:
        return True
    if not (lo < root.val < hi):
        return False
    return (is_valid_bst(root.left, lo, root.val) and
            is_valid_bst(root.right, root.val, hi))
```

<Locale lang="zh">

BST 中第 k 小的元素（230）：中序遍历到第 k 个即可。BST 的查找、插入都是 O(树高)，平衡时 O(log n)，退化成链时 O(n)。

## Level 3 · 最近公共祖先

LCA（236）：递归函数返回“在这棵子树里找到的 p 或 q（或它们的 LCA）”。

</Locale>

<Locale lang="en">

## Level 3 · Lowest common ancestor

LCA (236): the function returns p, q, or their LCA found within the subtree.

</Locale>

```python
def lowest_common_ancestor(root, p, q):
    if not root or root is p or root is q:
        return root
    left = lowest_common_ancestor(root.left, p, q)
    right = lowest_common_ancestor(root.right, p, q)
    if left and right:
        return root          # p and q are on different sides: root is the LCA
    return left or right     # both on one side (or neither)
```

<Locale lang="zh">

如果是 BST（235），更简单：p、q 都比根小就去左边，都比根大就去右边，否则根就是 LCA。

## 陷阱

<Note type="warning" title="常见错误">

- 验证 BST 只比较直接子节点。
- 混淆递归返回值与全局答案。
- 层序遍历不固定当前层大小。
- 深度很大时 Python 递归超限（可提一句可改迭代或 `sys.setrecursionlimit`）。
