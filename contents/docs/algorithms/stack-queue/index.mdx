## Level 0 · Stacks

Push openers; on a closer, the top must be its partner — the stack tracks the most recent unmatched item.

</Locale>

```python
def is_valid(s: str) -> bool:
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in s:
        if ch in pairs:
            if not stack or stack[-1] != pairs[ch]:
                return False
            stack.pop()
        else:
            stack.append(ch)
    return not stack          # leftovers mean unmatched openers
```

## Level 1 · 单调栈

### “下一个更大元素”怎么 O(n)？

每日温度（739）：对每一天，求几天后会出现更高温度。暴力 O(n²)。单调栈：栈里存**还没找到答案的天的下标**，温度从栈底到栈顶递减。新的一天比栈顶高时，栈顶那天的答案就找到了——弹出并记录。

</Locale>

<Locale lang="en">

## Level 1 · Monotonic stacks

Daily Temperatures (739): keep indexes of days still waiting for a warmer day, with decreasing temperatures; a warmer new day resolves and pops them.

</Locale>

```python
def daily_temperatures(temps: list[int]) -> list[int]:
    ans = [0] * len(temps)
    stack = []                                    # indexes, temps decreasing
    for i, t in enumerate(temps):
        while stack and temps[stack[-1]] < t:
            j = stack.pop()
            ans[j] = i - j                        # day i is j's next warmer day
        stack.append(i)
    return ans
```

<Locale lang="zh">

手推 `[73, 74, 75, 71, 69, 72, 76]`：

| i | 温度 | 弹出（找到答案） | 栈（下标） |
| --- | --- | --- | --- |
| 0 | 73 | — | [0] |
| 1 | 74 | 0 → 1 天 | [1] |
| 2 | 75 | 1 → 1 天 | [2] |
| 3 | 71 | — | [2, 3] |
| 4 | 69 | — | [2, 3, 4] |
| 5 | 72 | 4 → 1 天，3 → 2 天 | [2, 5] |
| 6 | 76 | 5 → 1 天，2 → 4 天 | [6] |

每个下标入栈、出栈各一次，O(n)。**柱状图中最大的矩形**（84）也是单调栈：对每根柱子，找左右第一个比它矮的位置，就知道它能延伸多宽。

## Level 2 · Monotonic deques

Sliding Window Maximum (239): keep indexes in a deque with decreasing values.

</Locale>

```python
from collections import deque

def max_sliding_window(nums: list[int], k: int) -> list[int]:
    dq, out = deque(), []                 # indexes, values decreasing
    for i, x in enumerate(nums):
        while dq and nums[dq[-1]] <= x:
            dq.pop()                      # smaller elements can never be a max again
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()                  # front fell out of the window
        if i >= k - 1:
            out.append(nums[dq[0]])       # front is the window max
    return out
```

<Locale lang="zh">

关键洞察：新元素 x 进来时，队尾比 x 小的元素**永远不可能再成为最大值**（x 比它们大，且比它们更晚离开窗口），可以直接丢掉。队头是当前窗口最大值；过期了就从队头弹出。O(n)。

<Note title="自测：到这里你应该能回答">

2. 队头什么时候需要弹出？

</Note>

</Locale>

<Locale lang="en">

Smaller tail elements can never be a maximum again (x is larger and leaves later), so drop them; the front is the max and is popped when it expires. O(n).

<Note type="warning" title="常见错误">

- 弹栈前不检查栈是否为空。
- 单调栈存值而不是下标，导致无法计算距离。
- 单调队列忘记弹出过期的队头。
