## Patterns

- Hash maps for **O(1) lookup / counting**
- Left and right pointers on sorted arrays
- Sliding window to maintain a range constraint
- Prefix sums turn a range query into the difference of two prefixes

## Skeleton

</Locale>

```ts
function twoSum(nums: number[], target: number) {
  const seen = new Map<number, number>()
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i]
    if (seen.has(need)) return [seen.get(need)!, i]
    seen.set(nums[i], i)
  }
}
```
