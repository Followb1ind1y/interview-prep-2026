## Level 0 · 哈希表

### 什么信号说明该用哈希？

- “找两个数满足某关系”、“是否出现过”、“计数 / 分组”、“去重”。
- 暴力解是双重循环 O(n²)，内层循环在“找某个值”——**把内层的查找换成哈希表的 O(1) 查找**。

### 模板：边遍历边查

Two Sum：找两个下标使 `nums[i] + nums[j] == target`。

</Locale>

<Locale lang="en">

## Level 0 · Hash maps

### Signals

Find a pair with a relation, "seen before?", counting or grouping, dedup. If the brute-force inner loop searches for a value, replace it with an O(1) hash lookup.

### Template: look up while iterating

Two Sum: find indices with `nums[i] + nums[j] == target`.

</Locale>

```python
def two_sum(nums: list[int], target: int) -> list[int]:
    seen = {}                      # value -> index
    for i, x in enumerate(nums):
        need = target - x
        if need in seen:           # O(1) lookup replaces the inner loop
            return [seen[need], i]
        seen[x] = i                # insert after checking, so x can't pair with itself
    return []
```

<Locale lang="zh">

手推 `nums = [2, 7, 11, 15]`，`target = 9`：

| i | x | need | seen（查之前） | 结果 |
| --- | --- | --- | --- | --- |
| 0 | 2 | 7 | 空 | 存 2→0 |
| 1 | 7 | 2 | 2→0 | 命中，返回 [0, 1] |

时间 O(n)，空间 O(n)。**先查再存**是关键细节：先存会让 `x + x == target` 的情况错误地和自己配对。

### 计数与分组

- 计数：`collections.Counter`。“两个字符串是不是字母异位词” → 比较两个 Counter。
- 分组：用一个“签名”作为键。“字母异位词分组” → 键为排序后的字符串（或 26 个字母的计数元组）。

</Locale>

<Locale lang="en">

Trace `[2, 7, 11, 15]`, target 9: store 2→0, then 7 needs 2 → found, return [0, 1]. O(n) time and space. Check before inserting so an element never pairs with itself.

### Counting and grouping

Count with `Counter` (anagram check compares counters); group by a signature key (sorted string or a 26-count tuple for grouping anagrams).

</Locale>

```python
from collections import Counter, defaultdict

def is_anagram(s: str, t: str) -> bool:
    return Counter(s) == Counter(t)

def group_anagrams(words: list[str]) -> list[list[str]]:
    groups = defaultdict(list)
    for w in words:
        groups[tuple(sorted(w))].append(w)   # signature as the key
    return list(groups.values())
```

## Level 1 · Opposing two pointers

### Signals

A sorted (or sortable) array and a pair relation, palindromes, in-place dedup. Pointers move inward, each step ruling out a whole row of candidates.

### Template: two sum on a sorted array

</Locale>

```python
def two_sum_sorted(nums: list[int], target: int) -> list[int]:
    lo, hi = 0, len(nums) - 1
    while lo < hi:
        s = nums[lo] + nums[hi]
        if s == target:
            return [lo, hi]
        if s < target:
            lo += 1        # nums[lo] + anything <= nums[hi] is too small: drop lo
        else:
            hi -= 1        # nums[hi] + anything >= nums[lo] is too large: drop hi
    return []
```

<Locale lang="zh">

为什么正确：如果 `nums[lo] + nums[hi] < target`，那么 `nums[lo]` 加上任何 `≤ nums[hi]` 的数都更小，`lo` 不可能是答案的一部分，可以放心丢掉。每步排除一个元素，O(n)。

### 3Sum：排序 + 固定一个 + 双指针

找所有不重复的三元组和为 0。排序 O(n log n)；固定第一个数 `i`，在其右侧用双指针找两数之和为 `-nums[i]`，O(n²)。**难点是去重**：

</Locale>

<Locale lang="en">

Correctness: if the sum is too small, `nums[lo]` with anything at most `nums[hi]` is too small, so `lo` can't be in the answer. One element eliminated per step, O(n).

### 3Sum: sort, fix one, two pointers

Sort (O(n log n)), fix `i`, and two-pointer for `-nums[i]` to its right — O(n²). The hard part is deduplication.

</Locale>

```python
def three_sum(nums: list[int]) -> list[list[int]]:
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue                          # skip duplicate first numbers
        lo, hi = i + 1, len(nums) - 1
        while lo < hi:
            s = nums[i] + nums[lo] + nums[hi]
            if s < 0:
                lo += 1
            elif s > 0:
                hi -= 1
            else:
                res.append([nums[i], nums[lo], nums[hi]])
                lo += 1
                while lo < hi and nums[lo] == nums[lo - 1]:
                    lo += 1                   # skip duplicate second numbers
                hi -= 1
    return res
```

### 什么信号？

## Level 2 · Sliding window

### Signals

Contiguous subarray/substring, longest/shortest/count under a constraint that changes monotonically as the window grows.

### Template: variable window (longest)

Longest substring without repeating characters:

</Locale>

```python
def length_of_longest_substring(s: str) -> int:
    count = {}
    best = left = 0
    for right, ch in enumerate(s):
        count[ch] = count.get(ch, 0) + 1          # 1. expand: add s[right]
        while count[ch] > 1:                      # 2. shrink while the window is invalid
            count[s[left]] -= 1
            left += 1
        best = max(best, right - left + 1)        # 3. window is valid: record
    return best
```

<Locale lang="zh">

手推 `s = "abcabcbb"`：

| right | 加入 | 窗口 | 是否收缩 | best |
| --- | --- | --- | --- | --- |
| 0–2 | a, b, c | abc | 否 | 3 |
| 3 | a | abca → 收缩到 bca | 是 | 3 |
| 4 | b | bcab → 收缩到 cab | 是 | 3 |
| … | | | | 3 |

每个元素最多进窗口一次、出窗口一次，所以虽然有嵌套 `while`，总复杂度仍是 **O(n)**——面试时要主动说出这个“摊还”理由。

### “最短”窗口

把模板的第 2、3 步调换：**窗口满足条件时**记录答案并收缩，尽量变短。例：长度最小的子数组（和 ≥ target）、最小覆盖子串。

### 什么时候不能用滑动窗口？

“和为 k 的子数组个数”且数组**有负数**时：扩大窗口和不一定变大，单调性被破坏，左指针不知道该不该动——要用 Level 3 的前缀和 + 哈希。

<Note type="warning" title="固定窗口">

窗口长度固定为 k 时（如“长度为 k 的子数组最大平均值”），每次右移一格：加入新元素、移出最左元素即可，不需要 `while`。

</Note>

### Shortest windows

Swap steps 2 and 3: while the window satisfies the constraint, record and shrink (minimum size subarray sum, minimum window substring).

### When windows fail

Counting subarrays with sum k when negatives exist breaks monotonicity — use prefix sums.

<Note type="warning" title="Fixed windows">

For fixed size k, add the new element and drop the oldest each step; no inner loop.

## Level 3 · 前缀和

### 前缀和是什么？

`prefix[i]` = 前 i 个元素之和（`prefix[0] = 0`）。区间 `[l, r]` 的和 = `prefix[r+1] - prefix[l]`，O(1) 回答任意区间和。

### 前缀和 + 哈希：和为 k 的子数组个数

子数组 `(j, i]` 的和为 k ⟺ `prefix[i] - prefix[j] = k` ⟺ `prefix[j] = prefix[i] - k`。遍历时用哈希记录**每个前缀和出现了几次**：

</Locale>

<Locale lang="en">

## Level 3 · Prefix sums

`prefix[i]` sums the first i elements (`prefix[0] = 0`), so any range sum is `prefix[r+1] - prefix[l]` in O(1).

### Prefix sums + hash: count subarrays summing to k

Subarray `(j, i]` sums to k iff `prefix[j] = prefix[i] - k`; count previous prefix sums in a hash map.

</Locale>

```python
def subarray_sum(nums: list[int], k: int) -> int:
    count = {0: 1}          # empty prefix: lets subarrays starting at index 0 count
    prefix = ans = 0
    for x in nums:
        prefix += x
        ans += count.get(prefix - k, 0)
        count[prefix] = count.get(prefix, 0) + 1
    return ans
```

<Locale lang="zh">

手推 `nums = [1, 2, 3]`，`k = 3`：

| x | prefix | 找 prefix - k | count 中的次数 | ans | 更新 count |
| --- | --- | --- | --- | --- | --- |
| 1 | 1 | -2 | 0 | 0 | 0:1, 1:1 |
| 2 | 3 | 0 | 1（子数组 [1,2]） | 1 | +3:1 |
| 3 | 6 | 3 | 1（子数组 [3]） | 2 | +6:1 |

**`count = {0: 1}` 这一步最容易漏**：它代表“空前缀”，让从下标 0 开始的子数组也能被统计到。

### 前缀积

“除自身以外数组的乘积”（不能用除法）：左侧前缀积 × 右侧后缀积，两次遍历，O(n)，可做到 O(1) 额外空间（输出数组不计）。

### Prefix products

Product of array except self without division: left prefix products times right suffix products, two passes, O(n), O(1) extra space besides output.
