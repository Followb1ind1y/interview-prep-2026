## Level 0 · Representation and traversal

Convert edge lists to adjacency lists (`defaultdict(list)`, both directions if undirected). Grids need no explicit graph: cells are nodes, four neighbors are edges.

### Grid DFS: Number of Islands

</Locale>

```python
def num_islands(grid: list[list[str]]) -> int:
    rows, cols = len(grid), len(grid[0])
    def sink(r: int, c: int) -> None:
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
            return
        grid[r][c] = '0'                              # mark visited
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            sink(r + dr, c + dc)
    count = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1                            # new island found
                sink(r, c)                            # erase all of it
    return count
```

<Locale lang="zh">

复杂度 O(行 × 列)：每个格子最多访问一次。注意：这里直接修改输入来标记访问；面试时要问“能否修改输入”，不能就用 `visited` 集合。网格很大时递归可能栈溢出，可改用 BFS。

## Level 1 · BFS 最短路

BFS 按“距离起点的步数”一层层扩展，第一次到达某节点时的层数就是最短距离——前提是**每条边权重相同**。

**入队时就标记 visited**，而不是出队时，否则同一节点会被多次入队。

**多源 BFS**：腐烂的橘子（994）——所有初始腐烂的橘子同时作为起点入队，层数就是时间。

</Locale>

<Locale lang="en">

## Level 1 · BFS shortest paths

BFS expands by distance, so the first arrival is the shortest path when edges are unweighted. Mark visited on enqueue, not dequeue. Multi-source BFS (Rotting Oranges, 994) starts from all sources at once.

</Locale>

```python
from collections import deque

def shortest_path_grid(grid: list[list[int]], start, goal) -> int:
    rows, cols = len(grid), len(grid[0])
    q = deque([(start, 0)])
    seen = {start}
    while q:
        (r, c), d = q.popleft()
        if (r, c) == goal:
            return d
        for dr, dc in ((1, 0), (-1, 0), (0, 1), (0, -1)):
            nr, nc = r + dr, c + dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 0 and (nr, nc) not in seen:
                seen.add((nr, nc))                    # mark on enqueue
                q.append(((nr, nc), d + 1))
    return -1
```

## Level 2 · Topological sort

Course Schedule (207/210) with Kahn's algorithm: emit zero in-degree nodes, decrement their neighbors, enqueue new zeros.

</Locale>

```python
from collections import defaultdict, deque

def find_order(n: int, prerequisites: list[list[int]]) -> list[int]:
    graph, indeg = defaultdict(list), [0] * n
    for course, pre in prerequisites:
        graph[pre].append(course)                     # pre -> course
        indeg[course] += 1
    q = deque(i for i in range(n) if indeg[i] == 0)
    order = []
    while q:
        u = q.popleft()
        order.append(u)
        for v in graph[u]:
            indeg[v] -= 1
            if indeg[v] == 0:
                q.append(v)
    return order if len(order) == n else []           # leftovers mean a cycle
```

<Locale lang="zh">

**环检测**：如果最后输出的节点数少于 n，剩下的节点入度永远不为 0——它们在环里。

### 并查集

维护“哪些元素属于同一组”，支持“合并两组”和“查询是否同组”，几乎 O(1)（路径压缩 + 按秩合并）。适合**边不断加入**的连通性问题：冗余连接（684）、连通分量数（323）。

</Locale>

<Locale lang="en">

## Level 3 · Union-find and Dijkstra

Union-find tracks groups with near-O(1) union and find (path compression, union by rank) — ideal when edges arrive over time: Redundant Connection (684), Connected Components (323).

</Locale>

```python
class UnionFind:
    def __init__(self, n: int):
        self.parent = list(range(n))
    def find(self, x: int) -> int:
        while self.parent[x] != x:
            self.parent[x] = self.parent[self.parent[x]]   # path compression (halving)
            x = self.parent[x]
        return x
    def union(self, a: int, b: int) -> bool:
        ra, rb = self.find(a), self.find(b)
        if ra == rb:
            return False                                   # already connected: this edge forms a cycle
        self.parent[ra] = rb
        return True
```

<Locale lang="zh">

### Dijkstra

边有**非负权重**时的最短路：用最小堆每次取出当前距离最小的节点，更新它的邻居。O((V + E) log V)。代表题：网络延迟时间（743）。有负权边时不能用 Dijkstra（需 Bellman-Ford），面试中一般点到为止。
