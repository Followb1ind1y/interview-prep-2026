## 提问顺序

1. 状态是什么？（通常是「做到 i / 用了 j」）
2. 决策是什么？（选或不选、从哪转移）
3. 初始值与边界
4. 能否压缩空间

## 代表题

| 题 | 模式 | 状态 |
| --- | --- | --- |
| Climbing Stairs | 1D | 待刷 |
| House Robber | 1D | 待刷 |
| Coin Change | Unbounded knapsack | 待刷 |
| Longest Increasing Subsequence | Subseq | 待刷 |
