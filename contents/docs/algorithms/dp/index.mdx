## Level 0 · 四步法

### 什么时候用 DP？

问题求**最大 / 最小值、方案数、能否做到**，并且大问题可以拆成**相互重叠的小问题**（同一个小问题会被反复计算）。暴力递归 / 回溯的复杂度是指数级，加上“记住已经算过的结果”就变成多项式级。

### 四步

1. **状态**：`dp[i]` 表示什么？要能用一句话说清楚（“前 i 个…的最…”）。
2. **转移**：`dp[i]` 怎么由更小的状态得到？
3. **初值**：最小的状态是什么？
4. **顺序**：保证计算 `dp[i]` 时，它依赖的状态都已算好。

## Level 0 · Four steps

Use DP for optimum, count, or feasibility with overlapping subproblems — memoizing turns exponential recursion polynomial. Steps: state (one sentence), transition, base, order. Climbing stairs both ways:

</Locale>

```python
from functools import cache

def climb_stairs_memo(n: int) -> int:
    @cache                                  # top-down: recursion + memo
    def f(i: int) -> int:
        if i <= 1:
            return 1
        return f(i - 1) + f(i - 2)
    return f(n)

def climb_stairs(n: int) -> int:
    a, b = 1, 1                             # bottom-up with O(1) space: f(i-2), f(i-1)
    for _ in range(n - 1):
        a, b = b, a + b
    return b
```

<Locale lang="zh">

状态 `f(i)` = 走到第 i 阶的方法数；转移 `f(i) = f(i-1) + f(i-2)`（最后一步走 1 阶或 2 阶）；初值 `f(0) = f(1) = 1`；顺序从小到大。没有记忆化的递归是 O(2ⁿ)，有记忆化是 O(n)。

## Level 1 · 一维 DP

### 打家劫舍（198）

不能偷相邻的房子，求最大金额。状态 `dp[i]` = 前 i 间房的最大金额；转移：偷第 i 间（`dp[i-2] + nums[i]`）或不偷（`dp[i-1]`），取较大。

### 零钱兑换（322）

用最少的硬币凑出金额。状态 `dp[a]` = 凑出金额 a 的最少硬币数；转移：`dp[a] = min(dp[a - c] + 1)` 对每种硬币 c。

</Locale>

<Locale lang="en">

## Level 1 · 1D DP

House Robber (198): `dp[i] = max(dp[i-1], dp[i-2] + nums[i])`. Coin Change (322): `dp[a] = min(dp[a - c] + 1)` over coins.

</Locale>

```python
def rob(nums: list[int]) -> int:
    prev2 = prev1 = 0                      # dp[i-2], dp[i-1]
    for x in nums:
        prev2, prev1 = prev1, max(prev1, prev2 + x)
    return prev1

def coin_change(coins: list[int], amount: int) -> int:
    INF = amount + 1
    dp = [0] + [INF] * amount              # dp[0] = 0: zero coins for amount 0
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], dp[a - c] + 1)
    return dp[amount] if dp[amount] != INF else -1
```

<Locale lang="zh">

手推零钱兑换 `coins = [1, 2, 5]`，`amount = 11`：`dp[5] = 1`（一枚 5），`dp[10] = 2`，`dp[11] = dp[10] + 1 = 3`（5 + 5 + 1）。复杂度 O(金额 × 硬币种数)。

**为什么贪心不行**：`coins = [1, 3, 4]`，凑 6：贪心先拿 4 再拿 1 + 1，共 3 枚；最优是 3 + 3，2 枚。

## Level 2 · 二维 DP

### 最长公共子序列（1143）

状态 `dp[i][j]` = `a` 的前 i 个字符和 `b` 的前 j 个字符的 LCS 长度。转移：最后一个字符相同则 `dp[i-1][j-1] + 1`，否则 `max(dp[i-1][j], dp[i][j-1])`。

### 编辑距离（72）

把 `a` 变成 `b` 的最少操作数（插入、删除、替换）。状态 `dp[i][j]` = `a` 前 i 个字符变成 `b` 前 j 个字符的最少操作数。

</Locale>

<Locale lang="en">

## Level 2 · 2D DP

LCS (1143): `dp[i][j]` over prefixes; equal last characters → diagonal + 1, otherwise max of up and left. Edit distance (72): minimum inserts, deletes, replaces between prefixes.

</Locale>

```python
def min_distance(a: str, b: str) -> int:
    m, n = len(a), len(b)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(m + 1):
        dp[i][0] = i                       # delete all i chars
    for j in range(n + 1):
        dp[0][j] = j                       # insert all j chars
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1] == b[j - 1]:
                dp[i][j] = dp[i - 1][j - 1]            # no operation needed
            else:
                dp[i][j] = 1 + min(dp[i - 1][j],       # delete a[i-1]
                                   dp[i][j - 1],       # insert b[j-1]
                                   dp[i - 1][j - 1])   # replace
    return dp[m][n]
```

<Locale lang="zh">

手推 `"horse"` → `"ros"`，答案 3（horse → rorse 替换 h，rorse → rose 删除 r，rose → ros 删除 e）。复杂度 O(m × n)，可优化到 O(n) 空间（只保留上一行）。

<Note type="tip" title="串联：NLP 评测">

- **编辑距离**是语音识别字错误率（WER / CER）的核心：WER = 词级编辑距离 / 参考文本词数（见 [Meeting Summarization](/docs/system-design/meeting-summarization) 的评测）。
- **LCS** 是 ROUGE-L 的核心：用候选摘要和参考摘要的最长公共子序列计算召回和精确率。

面试中能说出这层联系，会让一道普通 DP 题变成加分项。

</Note>

## Level 3 · 背包与 LIS

### 0/1 背包

每个物品只能选一次，容量限制下价值最大。一维写法的关键是**容量倒序遍历**，保证每个物品只被用一次（正序会变成可重复使用的“完全背包”，就是零钱兑换）。

```text
for 每个物品 (w, v):
    for cap in range(C, w - 1, -1):     # 倒序
        dp[cap] = max(dp[cap], dp[cap - w] + v)
```

代表题：分割等和子集（416）——能否选出一些数使和为总和的一半，就是容量为“总和 / 2”的 0/1 背包可行性问题。

### 最长递增子序列（300）

O(n²) DP：`dp[i]` = 以 `nums[i]` 结尾的 LIS 长度，`dp[i] = max(dp[j] + 1)` 对所有 `j < i` 且 `nums[j] < nums[i]`。进阶 O(n log n)：维护“每个长度的递增子序列的最小结尾”，用二分查找替换（见 [二分与堆](/docs/algorithms/search-sort) 的模板）。

## Level 3 · Knapsack and LIS

0/1 knapsack in 1D iterates capacity **downward** so each item is used once (upward gives unbounded knapsack, like coin change). Partition Equal Subset Sum (416) is feasibility with capacity sum/2. LIS (300): O(n²) with `dp[i]` ending at i; O(n log n) by binary-searching the smallest tail per length.

- 没说复杂度和空间优化的可能。
