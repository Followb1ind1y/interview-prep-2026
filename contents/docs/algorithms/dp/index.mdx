## 提问顺序

1. 状态是什么？（通常是「做到第 i 个 / 用了 j 个」）
2. 决策是什么？（选还是不选、从哪个状态转移过来）
3. 初始值和边界
4. 能不能压缩空间

## Questions to ask, in order

1. What's the state? (Usually "up to index i / having used j")
2. What's the decision? (Take it or skip it, and which state it transitions from)
3. Initial values and boundaries
4. Can the space be compressed?
