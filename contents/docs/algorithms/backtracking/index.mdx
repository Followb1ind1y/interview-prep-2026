题目要求“**列出所有**”满足条件的组合、排列、方案时，几乎都是回溯。回溯 = 在一棵“决策树”上做 DFS：每一层做一个选择，走到底记录答案，回来时撤销选择。掌握一个模板 + 三种变体即可。

## Level 0 · Template

</Locale>

```python
def subsets(nums: list[int]) -> list[list[int]]:
    res, path = [], []
    def backtrack(start: int) -> None:
        res.append(path[:])               # every node of the tree is a subset (copy!)
        for i in range(start, len(nums)):
            path.append(nums[i])          # choose
            backtrack(i + 1)              # explore with later elements only
            path.pop()                    # undo
    backtrack(0)
    return res
```

<Locale lang="zh">

三个要点：

- **`path[:]` 要拷贝**：`path` 是同一个列表，后面还会被修改；直接 `append(path)` 会让结果全变成空列表。
- **`start` 控制只往后选**，避免 `[1,2]` 和 `[2,1]` 重复。
- **撤销**（`pop`）让 `path` 回到选择前的状态，才能尝试下一个分支。

## Level 1 · Three variants

Subsets: order irrelevant, `start`, record at every node (78). Combinations / combination sum: `start` + remaining target, record at zero (39). Permutations: order matters, a `used` array, record at full length (46).

</Locale>

```python
def combination_sum(candidates: list[int], target: int) -> list[list[int]]:
    res, path = [], []
    def backtrack(start: int, remain: int) -> None:
        if remain == 0:
            res.append(path[:])
            return
        for i in range(start, len(candidates)):
            if candidates[i] > remain:
                continue
            path.append(candidates[i])
            backtrack(i, remain - candidates[i])   # i, not i + 1: reuse allowed
            path.pop()
    backtrack(0, target)
    return res

def permute(nums: list[int]) -> list[list[int]]:
    res, path, used = [], [], [False] * len(nums)
    def backtrack() -> None:
        if len(path) == len(nums):
            res.append(path[:])
            return
        for i in range(len(nums)):
            if used[i]:
                continue
            used[i] = True
            path.append(nums[i])
            backtrack()
            path.pop()
            used[i] = False
    backtrack()
    return res
```

<Locale lang="zh">

组合总和允许重复使用同一个数，所以递归传 `i` 而不是 `i + 1`。

## Level 2 · 去重与剪枝

### 输入有重复元素

子集 II（90）：`[1, 2, 2]` 不能输出两次 `[1, 2]`。做法：**先排序**，在同一层循环中跳过和前一个相同的元素：

```text
for i in range(start, n):
    if i > start and nums[i] == nums[i - 1]:
        continue          # 同一层已经用这个值开过一个分支
```

注意是 `i > start` 而不是 `i > 0`：只跳过**同一层**的重复，不同层（更深的递归）可以使用相同的值。

### 剪枝

在进入分支前判断它不可能产生答案就跳过。组合总和中 `candidates[i] > remain` 就是剪枝；若先排序，可以直接 `break`（后面的更大）。N 皇后用集合记录已占用的列和对角线，O(1) 判断是否冲突。

### 复杂度怎么讲？

回溯是指数级的：子集有 2ⁿ 个，每个拷贝 O(n)，共 O(n·2ⁿ)；排列 O(n·n!)。面试时直接说出来，并说明“输出本身就有这么大，所以无法更优”。

## Level 2 · Dedup and pruning

Subsets II (90): sort, then skip `nums[i] == nums[i-1]` when `i > start` — same-level duplicates only; deeper levels may reuse the value. Prune before branching (`candidates[i] > remain`; after sorting, `break`). N-Queens tracks occupied columns and diagonals in sets. Complexity is exponential — O(n·2ⁿ) for subsets, O(n·n!) for permutations — and the output size makes it unavoidable.
