不是「把之前聊天总结一下」。Anthropic 讨论过 context reset 和接近 limit 时的 context anxiety。

## 需要掌握

应保留例如：

- current goal
- completed tasks
- important decisions
- files changed
- errors
- unresolved issues
- tool state
- user preferences

## 机制

```
Long trajectory
       ↓
Context grows
       ↓
Near context limit
       ↓
Summarize / compact
       ↓
New context
       ↓
Continue
```

## 三级回答

### Level 1 — Definition

轨迹变长后，主动压缩 context 以便继续工作。

### Level 2 — Mechanism

摘要 + 结构化状态替换原始 observation。必要时 reset 再注入关键状态。

### Level 3 — Engineering

丢掉错误和未决问题会导致重复失败。Coding agent 必须保留改过的文件和测试红灯。
