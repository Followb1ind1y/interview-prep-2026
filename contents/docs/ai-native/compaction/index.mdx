## 三级回答

### Level 1 — 定义

执行轨迹变长之后，主动压缩上下文，好让工作继续下去。

### Level 2 — 机制

用摘要 + 结构化状态替换原始的观察记录。必要时直接重置上下文，再把关键状态注入回去。

### Level 3 — 工程

丢掉错误信息和未解决的问题，会导致重复犯同样的错。Coding agent 必须保留改过的文件和失败的测试。

## Three-level answers

### Level 1 — Definition

Proactively compressing context once the trajectory gets long, so the work can continue.

### Level 2 — Mechanism

Replace raw observations with a summary plus structured state. When needed, reset the context and inject the key state back in.

### Level 3 — Engineering

Drop the errors and open issues and the agent repeats the same failures. A coding agent has to keep the files it changed and the tests that are still failing.
