## 三级回答

### Level 1 — 定义

Harness 是 agent 的运行环境：它能碰到什么、怎么拿到反馈、上下文怎么维护。

### Level 2 — 机制

模型只负责输出 token。Harness 负责执行工具、管理权限、截断 / 压缩上下文、跑测试、保存状态。

### Level 3 — 工程

面试可能会问「你会怎么搭一个 coding agent 的 harness？」答案不是再包一层 LLM 调用，而是规格说明、工具接口、沙箱和验证闭环。

## Three-level answers

### Level 1 — Definition

The harness is the agent's operating environment: what it can touch, how it gets feedback, and how its context is maintained.

### Level 2 — Mechanism

The model only produces tokens. The harness executes tools, manages permissions, truncates or compacts context, runs tests, and persists state.

### Level 3 — Engineering

You may get asked "How would you build a coding-agent harness?" The answer isn't another wrapper around an LLM call — it's specifications, the tool surface, a sandbox, and a verification loop.
