## 三级回答

### Level 1 — 定义

MCP 是模型和外部能力之间的协议，覆盖工具、资源和提示模板，而不是某一家模型私有的 function calling。

### Level 2 — 机制

Host 管理会话和上下文边界。Client 负责连接 server。Server 暴露 primitives。传输可以是 stdio 或 Streamable HTTP，消息格式是 JSON-RPC。双方会协商各自支持的能力。

### Level 3 — 工程

Function calling 是模型 API 的参数形状；MCP 是工具生态和安全边界的协议。Server 默认不应该看到完整对话。工具发现让 harness 能在运行时找到可用的能力。

## Three-level answers

### Level 1 — Definition

MCP is a protocol between models and external capabilities — tools, resources, and prompt templates — rather than one vendor's private function-calling format.

### Level 2 — Mechanism

The host manages sessions and the context boundary. The client connects to servers. Servers expose primitives. Transport is stdio or Streamable HTTP, and messages are JSON-RPC. Both sides negotiate capabilities.

### Level 3 — Engineering

Function calling is the argument shape of a model API; MCP is a protocol for a tool ecosystem and its security boundary. Servers shouldn't see the full conversation by default. Tool discovery lets the harness find capabilities at runtime.
