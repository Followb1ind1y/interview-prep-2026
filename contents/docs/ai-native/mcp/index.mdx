## 三级回答

### Level 1 — Definition

MCP 是模型与外部能力之间的协议：工具、资源和提示模板，而不是某家模型的私有 function calling。

### Level 2 — Mechanism

Host 管会话和 context 边界。Client 连 server。Server 暴露 primitives。传输可以是 stdio 或 Streamable HTTP，消息是 JSON-RPC。双方协商 capability。

### Level 3 — Engineering

Function calling 是模型 API 的参数形状；MCP 是工具生态和安全边界的协议。Server 不应默认看到完整 conversation。Tool discovery 让 harness 在运行时找能力。
