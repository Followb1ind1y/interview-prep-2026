状态可以包括 Task、Plan、Progress、Files、Tool results、Memory、Errors、Environment。

## 需要掌握

显式状态才能暂停、恢复、多 worker。

## 机制

```
Conversation  =  token 历史（易爆、难恢复）
State         =  任务进度的结构化事实
```

## 三级回答

### Level 1 — Definition

Agent state 是可序列化的工作进度，不是聊天记录本身。

### Level 2 — Mechanism

把 plan、文件集合、失败信息写入 store / 磁盘。恢复时重建 working set，而不是回放全部 token。

### Level 3 — Engineering

后台 agent 必须 checkpoint。没有 state 就无法做 long-running reliability。
