## 三级回答

### Level 1 — 定义

在受限的环境里执行模型生成的、不可信的动作，限制出错时的影响范围。

### Level 2 — 机制

独立的文件系统、不给或只给受限的网络、CPU / 内存上限、凭证不放进容器。权限按工具逐个授予。

### Level 3 — 工程

没有沙箱的终端工具，就等于远程代码执行漏洞。生产环境的 coding agent 必须默认隔离，再按需开放网络。

## Three-level answers

### Level 1 — Definition

Running untrusted, model-generated actions inside a restricted environment to limit the blast radius.

### Level 2 — Mechanism

A separate filesystem, no network or restricted network, CPU and memory limits, and credentials kept out of the container. Permissions are granted per tool.

### Level 3 — Engineering

A terminal tool without a sandbox is remote code execution. Production coding agents must be isolated by default, with network access opened only as needed.
