## 本栏约定

- **分工**：Compaction 管“模型这一轮看到什么”；Agent State 管“任务做到哪、怎样不重复副作用”，两页不重复。
- **贯穿案例**：修复猫粮客服把“订单还没到”误判成“未发货”的 bug。订单真实状态由 API 决定；修复靠实际 diff、测试与运行结果验收。示意文件和测试数字不代表项目实测。
