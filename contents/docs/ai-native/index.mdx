建议在 [Agent Loop](/docs/agent/loop)、[Context Engineering](/docs/context)、[Evaluation](/docs/evaluation) 和 [Production AI](/docs/production) 后读本栏。目标是能解释：coding agent 怎样读仓库、改代码、得到外部反馈、在长任务中恢复，并把不可信执行限制在安全边界里。

贯穿七页的**教学任务**是修复猫粮客服把“订单还没到”误判成“未发货”的 bug。订单的真实状态由 API 决定；代码修复要靠实际 diff、测试与运行结果验收。示意文件和测试数字不代表你的项目实测。

## 建议学习顺序

1. **先懂控制层：** [Agent Harness](/docs/ai-native/harness) 讲模型、工具、状态和执行环境各负责什么。
2. **再看编码循环：** [Claude Code / Codex](/docs/ai-native/coding-workflow) 讲仓库工作流；[Agentic Coding](/docs/ai-native/agentic-coding) 讲复现、测试和验证。
3. **长任务不丢状态：** [Agent State](/docs/ai-native/agent-state) 讲 checkpoint 与恢复；[Context Compaction](/docs/ai-native/compaction) 讲保留哪些证据。
4. **最后接外部系统与执行：** [MCP](/docs/ai-native/mcp) 讲 Host / Client / Server、能力与授权；[Sandbox](/docs/ai-native/sandbox) 讲文件、网络、凭证和资源隔离。

Read this after [Agent Loop](/docs/agent/loop), [Context Engineering](/docs/context), [Evaluation](/docs/evaluation), and [Production AI](/docs/production). The goal is to explain how a coding agent inspects a repository, edits code, gets external feedback, resumes long work, and contains untrusted execution.

Our running teaching task fixes a support bug that treats “not arrived” as “not shipped.” The order API provides true state; actual diffs, tests, and runtime behavior establish whether the patch works. Sample files and test counts are illustrative.

## Suggested order

1. **Control layer:** [Agent Harness](/docs/ai-native/harness) separates model, tools, state, and execution.
2. **Coding loop:** [Claude Code / Codex](/docs/ai-native/coding-workflow) explains repository work; [Agentic Coding](/docs/ai-native/agentic-coding) covers reproduction and verification.
3. **Long-running work:** [Agent State](/docs/ai-native/agent-state) covers checkpoints and resume; [Context Compaction](/docs/ai-native/compaction) preserves the evidence needed to continue.
4. **External capability and execution:** [MCP](/docs/ai-native/mcp) covers host/client/server, capabilities, and authorization; [Sandbox](/docs/ai-native/sandbox) covers filesystem, network, credentials, and resources.

All seven topic pages have 4–5 bilingual Levels, one running case, self-checks, and interview questions. Practice with `/drill ai-native/<page slug>`; generating notes does not count as mastery.
